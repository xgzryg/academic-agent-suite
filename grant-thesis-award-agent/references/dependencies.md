# 独立包与外部运行条件

所有主入口、22个功能分支、共享规则、模板和7个工具脚本都随包提供；内部流程不调用其他已安装agent或skill。不捆绑完整Python、Office、浏览器、模型服务或数据库，也不携带任何API密钥。

| 功能 | 实际需要 | 缺少时可交付 |
| --- | --- | --- |
| 任务路由、构思、写作与审读 | 能读取本地技能文件的AI宿主及其模型 | 此包本身不是独立聊天程序 |
| 安装、引用结构审计、SVG/draw.io图形 | Python 3.10+，标准库 | 宿主可直接读流程；手动复制安装 |
| PubMed | Python 3.10+、可访问NCBI的网络 | 保留检索式、已取得证据及失败状态 |
| DOCX XML提取 | Python标准库 | 宿主现有文件阅读工具 |
| 新DOCX / 精确修订 | python-docx / lxml | Markdown或精确修改建议，说明未改实际文件 |
| PDF文字 / 页图 | pypdf / pypdfium2、Pillow | 宿主现有PDF工具；未读页明确列出 |
| 基础PPTX | python-pptx、Pillow | 大纲与逐页讲稿 |
| Word/PPTX页面核查 | 实际Word、LibreOffice或可用渲染服务 | 只声明内容和结构检查，版面未验证 |
| 复杂科学插画 | 宿主实际图像生成/编辑工具及相应服务 | 结构草图和绘图需求，不假称已生成插画 |
| 独立子agent审修 | 宿主真实委派工具 | 透明说明后做顺序多视角审读 |

可选库列于 [requirements.txt](../requirements.txt)，安装脚本不自动安装它们。无需为了纯文字任务安装全部库；需要配置环境时按当前用户与宿主的授权规则执行。

PubMed脚本可读取环境变量NCBI_EMAIL和NCBI_API_KEY；没有密钥也可在NCBI公开访问条件下使用。不要写密钥进提示词、仓库、报告或安装包。联网检索与全文访问始终受实际网络和公开访问条件限制。

宿主是否把技能显示在菜单、是否支持自然语言隐式调用、是否提供真实子agent，取决于宿主实现；复制目录不等于安装了这些宿主能力。包内路径以当前安装目录解析，不依赖开发机盘符。
