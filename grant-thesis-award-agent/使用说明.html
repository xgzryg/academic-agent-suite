认识与安装

这是一套供AI宿主读取的技能包。安装后通过对话调用，不是双击运行的桌面软件。

解压独立安装包

打开ZIP，保留唯一顶层文件夹 grant-thesis-award-agent。其中应直接包含 SKILL.md、skills、scripts 和本说明书。

复制到宿主实际使用的技能目录

先确定当前宿主配置的skills父目录，将整个文件夹放进去。不要把22个子技能分别拆出去，也不需要改全局AGENTS.md。

按需用已有Python辅助安装

脚本会把整包复制到指定父目录；若同名安装已存在则停止，保留旧版本。它不安装Python、Office或其他依赖。

python "<解压目录>/grant-thesis-award-agent/scripts/install.py" --destination "<宿主实际skills父目录>" --dry-run
python "<解压目录>/grant-thesis-award-agent/scripts/install.py" --destination "<宿主实际skills父目录>"
刷新宿主并首次调用

按宿主支持的方式刷新技能或重开会话；随后使用下方提示词。不支持$调用的宿主，可让它读取包内SKILL.md并执行。

请使用 $grant-thesis-award-agent。

可以只润色一段、画一张路线图或检查一项申报字段。局部任务会直接处理，无须每次重新盘点整套项目。

基金选题与科学问题

结合研究基础、领域证据与资源期限，比较选题并凝练科学问题、假说和预实验重点。

输入、产物与调用方法

  • 资助机构、年度与项目类别

  • 需要时的预实验建议

使用范围

  • 不虚构个人基础或文献空白
  • 不承诺中标率，不套固定预实验完成比例
  • 适用的机构年度规则与AI要求分别核对

审稿—返修循环怎么用

普通预审不会自动进入循环。明确开启后，助手先核对宿主是否具备真实委派工具，再由不同子agent负责审读与修改。

  1. 审读者依据当前稿、真实证据与目标提出具体问题。
  2. 另一个修改者在已授权范围落实修改，保留待补事实。
  3. 修改后交回审读者复查，包括最后一次修改。
  4. 达到目标、达到上限，或因缺证据而无法继续改善时停止并交付。

若设置最多N轮返修，最多进行N次修改和N+1次审读。达到轮数上限不代表通过；未解决事项、实际轮数和停止原因会明确列出。

没有真实委派工具时，助手会说明能力限制。顺序多视角检查可以作为透明替代，但不会被称为独立子agent循环。

常见问题

是否需要另装其他agent或22个子技能？

不需要其他本机agent。保持一个完整文件夹即可；需要文件处理时，才检查当前环境是否具备对应公共库。外部运行条件不会因复制技能自动出现。

能不能从零自动写完整论文或申请书？

在机构规则允许、资料足够且范围已授权时，可以连续组织和撰写工作材料。实际数据、方法记录、伦理、权属、贡献和应用证明必须来自真实资料；缺项会列明。对有AI使用限制的资助或学校情境，按适用规则提供辅助工作。

2027或某省基金是否已经预装所有最新规则？

没有。需要读取对应年度、具体省份/计划/类别的正式指南及当前表格，再按实际要求适配。标题写着某年份的经验材料不能替代正式政策。

可以只做降重或去AI味吗？

可以在保留事实和必要引用的前提下改善表达、处理实际相似性报告指出的问题。不承诺检测器分数、查重率或规避平台检测，也不隐藏借用来源。

是否会自动安装、上传或提交申请？

本包的日常调用不自动安装环境、发送材料、签发证明或提交申请。外部动作依据用户具体授权及宿主规则处理。此HTML只用于阅读和生成提示词。

怎么接着上次的工作继续？

指出当前主稿、已确认决定、人工固定项和本次目标。助手先读取当前文件与已有项目记录，继续未完成部分；不会从旧示例重建覆盖最新人工稿。

安装目录已有同名文件夹怎么办？

安装器会停止并保留原安装。先检查旧包和人工修改，再决定备份及替换范围；不要把新旧分支随意混在一起。
