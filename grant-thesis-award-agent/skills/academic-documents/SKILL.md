# Word 与 PDF

遵守 [共享规则](../../references/shared-rules.md)。脚本 [document_io.py](../../scripts/document_io.py)、[pdf_io.py](../../scripts/pdf_io.py) 的命令与输入见 [工具指南](../../references/tools.md)。

## 阅读

- DOCX提取正文段落与表格，以及页眉页脚、批注、脚注等可读XML内容。输出不是排版预览，批注上下文不自动等于精确选区。遇到现有修订须区分插入/删除状态，不把混合抽取文本当唯一已接受正文。
- PDF按页抽取并核对缺字、映射乱码与截图。低字数提示只是线索；高字数也可能是乱码。需要理解图表和截图时渲染相关页并真正查看图片。
- 先盘点图片、表、公式、引用域、交叉引用和学校模板特有对象，确定任务需要处理哪些对象。

## 创建与修改

- from-json生成标题、段落和普通表格组成的新DOCX；适合审读报告和简单工作材料，不等于复刻复杂学校模板。
- replace只在唯一位置、单一文本run内精确替换；--track可生成真正的w:ins/w:del修订。已有修订或复杂run被拒绝时，用宿主可用的文档工具定位处理，或者交付精确修改建议和未执行项，不拆碎公式或抹平整段格式。
- 大型学位论文格式整理须沿用当前真实模板和文档样式，不按章节号把整段文本硬塞入旧模板。目录、域更新和页码以实际Word/兼容编辑器结果为准。
- 新输出名默认保留原件。用户已授权修改当前工作稿时可以续用，但要先读当前稿；不得从旧数据重建覆盖人工固定成品。

## 核查与交付

对受影响数值、单位、段落、表格或修订进行内容回读；涉及版式时使用可用Word/LibreOffice导出PDF并查看页面。没有渲染器则明确“结构与内容已核查，页面布局未验证”，不说投稿/提交排版已全部合格。工具不会自动安装Office或公共库。

提供实际文件、编辑范围、保留对象、待处理问题与检查限度。需要答辩材料时转 [presentation-support](../presentation-support/SKILL.md)。
