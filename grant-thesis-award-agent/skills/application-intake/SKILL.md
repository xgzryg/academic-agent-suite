# 材料接收与任务定位

遵守 [共享规则](../../references/shared-rules.md)。读取用户实际提供的文件内容，而非仅按文件名判断；PDF乱码或图示见 [文档处理](../academic-documents/SKILL.md)。

1. 提取任务目标、当前稿、受保护原件、输出目录、编辑范围和完成标准。已有答案复用。
2. 基金识别机构/年度/类别/学科及现有研究积累；论文识别学校/学位/学科/模板及实际分析结果；奖项识别组织/年度/类别/候选项目与证明材料。局部语言修改不强制提供整套信息。
3. 多文件按内容分为当前正文、事实与数据、模板要求、参考证据、历史稿。相同编号不证明同一对象；按内容与依赖识别。
4. 标记真正影响后续工作的缺项：不可代填的事实、相互矛盾的数值/状态、无法确定的当前稿、关键科学方向。只询问依赖这些内容的部分；其他任务继续。
5. 生成简洁简报：目标文种与阶段；使用输入；已确认决定；准备依次调用的分支；交付物；具体待补项。短任务可直接在答复内表达，无须创建档案。

多阶段任务可使用 [任务简报模板](../../references/task-brief-template.md)，保持一份当前记录。年度规则按 [当前要求](../../references/current-requirements.md) 核查，不能把经验示例当正式指南。

基金任务涉及国自然、省级自然科学基金、研发/转化计划、博士后及人才支持时，进一步读 [基金深入方法](../../references/grant-deepening.md) 第1部分。完整申报的形式要求与科学预审分开；省份、计划、类别不明时不能套用同名项目规则，局部编辑不因此停下。

交付简报后立即进入主入口路由中的实际分支，不以“请确认计划”作为每阶段默认终点。若用户明确要求先审批研究方案，则完成可审阅方案后按该要求等待。
