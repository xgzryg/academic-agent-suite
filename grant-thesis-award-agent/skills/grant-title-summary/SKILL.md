# 基金标题、摘要与关键词

读取[共享规则](../../references/shared-rules.md)和[当前要求](../../references/current-requirements.md)。标题与摘要压缩当前项目的科学内容，不新增研究对象、目标、结果或首创主张。

## 输入和分流

- 当前项目正文、科学简报或作者摘要，已有题目和研究目标。
- 资助机构、年度、类别、学科指南及标题/摘要长度与语言要求。
- 必须保留的关键词、术语、已有标题偏好；已给出则不再询问。
- 任务是标题拟定、摘要修改、双语对应或篇幅压缩。

只有题目而缺少研究内容时，可以诊断题目清晰度并列出决定命名的必要信息，不能据题目编造完整项目。适用2026国自然时，有作者稿则修订，没有稿则提供摘要结构和写作要点等辅助材料，遵循当前AI使用要求。

## 标题流程

1. 提取对象/条件、中心问题、核心关系、必要方法与预期贡献，区分哪些是标题必备、哪些应留在摘要。
2. 检查现有标题是否过宽、方法堆砌、结论先行或与真实内容不符。
3. 按用户需求给少量不同侧重点的候选；每项说明突出什么、删去什么非必要信息及适用理由，不凑固定题数。
4. 指南中真实相关术语可使用，但不能为了“政策契合”把不存在的内容加入标题；学科适配不代替科学真实性。
5. 需要相近题目检索时使用[文献与证据](../evidence-research/SKILL.md)，说明检索到的相似点。相同用词不等于实质重复，未检出相似标题也不证明研究首创。
6. 用户明确选定某项后直接沿用，后续只有正文改变导致不一致时再提出有据修订。

## 摘要流程

1. 从作者材料提取五项：具体背景/问题、现有缺口、真实前期支撑、拟开展的主要工作、潜在科学价值；是否设显式小标题由模板决定。
2. 用有限篇幅说明问题为何值得解决、拟如何回答；方法只保留能识别研究设计的关键内容。
3. 前期成果使用其真实完成状态；拟研究工作用计划表达，预期发现不得改成已经证实。摘要不能承诺正文没有的方法、样本或效果。
4. 对用户草稿进行压缩、改写或结构调整时，逐项保留事实、对象、方向、数量、关键方法和不确定性。
5. 依正式限制计数：中文字符/字数、英文词数、行数或页面是不同口径；使用要求指定的口径并说明测量方法，不套所有机构统一250词或400字。
6. 没有明确引用要求时通常不为摘要增加整套参考文献；必须保留/核实的引用按实际模板处理。

## 双语与关键词

- 英文版以核对后的中文科学内容或用户指定主语种为准，按学术英文自然表达，不逐词硬译。
- 核对对象、研究设计、方向、数量、时间状态、假说与预期价值是否一致；一方含有额外结论时纠正或指出。
- 术语首次解释方式与当前模板和全文一致；必要时列小型中英术语对照，避免同一技术多个译名。
- 关键词覆盖问题、对象和核心方法；数量和分隔方式以实际提交字段为准。

## 交付与核查

输出所需的标题候选/建议题目、摘要修改稿或作者写作提纲、中英文对应与关键词。附简短理由、实际计数和具体待核项，不对每句附重复解释。

交付前核对题目—摘要—正文的一致性。需要保真修改或排版时调用[学术文档](../academic-documents/SKILL.md)。本分支不声称预测评审偏好、中标概率或正式通过机构审查；不能以声明替代适用情境下作者的实质撰写与核验。
