# 科技奖申报审查

核查当前申报工作稿的事实、栏目和证明关系，给出定位清楚的修改意见。遵守[共享规则](../../references/shared-rules.md)，目标资格和格式依据[当前要求](../../references/current-requirements.md)。这是一项辅助审查，不代表主办方资格审核或正式专家结论。

## 输入与范围

读取用户指定当前稿、实际年度模板、相关证据映射和附件。先判断是只读评审、局部修改、全文修订还是用户明确开启循环。只读任务不改源文件；授权修改沿用当前编辑范围和人工固定项。原件保留，使用已有工作副本或另存指定成果。

## 执行

1. 核实本次必须检查的对象和规则：奖项类别与年份、模板字段、所用附件及已确认的主张。只有过时指南时说明适用性未确认，不把历史要求视作现行条件。
2. 按[审查要点](references/review-focus.md)检查实际内容，优先找会改变科学主张、资格理解或证明关系的问题。把事实错误、待核材料和仅文字表达改善分开，不制造固定问题数或给无依据评分。
3. 每项意见写出文稿位置、问题、依据、实际影响及最小可行修复。来源未取到时写待核及受影响表述，不假定其为假，也不静默删除未知引用或附件。
4. 授权修订时调用[修订衔接](../review-revision/SKILL.md)和[文档分支](../academic-documents/SKILL.md)，同步范围内的简介、核心正文、数字与附件引用。需新增比较证据时调用[证据检索](../evidence-research/SKILL.md)，保持检索范围透明。
5. 修订完成后复查本次受影响的主张及其依赖。只有新发现、失败或实质更改才扩展检查；达到循环上限不等于通过，实际未解决项继续列明。

## 输出与停止点

输出可定位的审查意见、授权后的工作稿和必要未决项，可用[审查记录模板](templates/award-review.md)。若内容正确，明确说明相关部分已核对无误。资格、应用期限、证明真实性或权属关系仍缺关键输入时，暂停依赖该事实的最终结论，继续已授权独立部分。

不得伪造签名印章、第三方证明、应用效益、专利授权、获奖和贡献事实；不得为了通过审查而降低事实标准。正式报送或对外发送只在适用授权下执行。
