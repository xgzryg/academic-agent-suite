# 科技奖审查要点

只检查本任务实际涉及的内容，检查应能影响修改或结论。

| 具体对象 | 实际错误或不足 | 应采取的动作 |
|---|---|---|
| 栏目及字数 | 当前目标模板与工作稿不匹配 | 按适用模板整理；未取得模板则保留待核 |
| 发现/创新 | 简介、核心正文与附件支持的含义不一致 | 改写至证据支持范围并同步关联段落 |
| 数值与日期 | 单位、累计/当期、完成/应用时间相互矛盾 | 核对原表和证明，未经确认不择优取值 |
| 国内外比较 | 对象不同、测试条件不明、来源过期或缺失 | 限定比较范围或补证，不编写优势排序 |
| 第三方评价 | 自评冒充外评或局部评价扩大至全项目 | 恢复真实主体、对象、原意和出处 |
| 应用效益 | 重复计入、口径混淆或缺证明 | 重算仅在授权范围内；否则明确待核口径 |
| 完成人与单位 | 贡献、作者、发明人或权属角色被混同 | 按现有材料分别核对，待用户确认真实归属 |
| 证明附件 | 编号失效、引用缺页、申请状态写为授权 | 修复引用和状态，标明缺项；不生成冒充原件 |

文字更流畅不等于申报条件已满足。模拟专家反馈可辅助判断表达问题，但不能替代官方资格、签章真实性或技术水平认定。
