# 绪论与文献综述

先读取[共享规则](../../references/shared-rules.md)；涉及学校格式和标准版本时读取[当前要求](../../references/current-requirements.md)。本分支将证据组织成围绕研究问题的论述，适用于完整章节及局部补写。

## 输入与范围

复用已确认题目、研究问题、章节大纲、学校要求和现有文献。辨明用户要从给定文献写作、核对现稿、补查某个主张，还是重新检索。用户明确限定离线或仅用给定材料时遵守限制，并准确说明材料范围；不要把未执行的检索写进方法记录。

全文 PDF、Word 或截图由[学术文档](../academic-documents/SKILL.md)读取。抽取乱码、低文本页、图表和截图需实际查看；无法读取的部分记录缺口。只有摘要时只能依据摘要可支持的内容，不声称全文精读。

## 执行

1. **拆分问题与主题。** 围绕对象、概念、方法、关键发现和待解决问题组织主题，按学校安排确定背景、研究现状、意义与本论文切入点。已有结构只在必要处调整。
2. **组织检索。** 需要检索时使用[证据检索](../evidence-research/SKILL.md)，按学科选用宿主实际渠道，记录日期、数据库和筛选范围。明确零结果、请求失败、未检索和未取得全文。PubMed 等单库只代表其实际覆盖范围；系统综述请求须先明确相应检索与筛选方法，不能将普通叙述综述称为系统综述。
3. **建立轻量证据笔记。** 每篇保留题名及可靠标识、研究对象与物种、设计、样本或资料范围、关键方法、主要发现、局限和当前主题用途。引用关键数字或结论时记录可定位的页码、表图或段落。根据文献数量用表格或结构化文件；无需为少量段落另建复杂数据库。
4. **分别核对身份和支持关系。** DOI、PMID、作者、年份和来源解决“是哪篇”；阅读原文解决“是否支持本句”。无法核实的元数据保留待查状态，不能默认 verified 或补造作者题名。相似关键词仅提示候选文献，不意味着结论被支持。
5. **先综合再写作。** 以主题段落呈现共识、差异、方法限制和未解决问题，再说明本研究的合理位置。按信息权重引用，不逐篇堆摘要、不逐句硬配引用。研究空白必须与实际检索和证据相容，避免“首次”“完全空白”等未证实判断。
6. **核对关键概念。** 疾病或亚型、研究人群、物种、样本分母、时间范围和结果方向不可互换；综述转述不能把动物结果改成人群结果，也不能把相关性写成机制证实。原文不支持时修改论断，而非搜一个近似引用保持原断言。
7. **合并章节。** 统一术语、缩略语和叙事次序，删除重复背景，保留作者核心观点与必要引用。范围较大时分主题形成工作稿后整合，记录已完成主题与仍缺材料。

## 交付

交付所需绪论、研究现状或综述文字，以及对应引用。按任务需要附文献矩阵、检索与阅读范围说明或待核验事项；不要把内部检索过程堆入正文。要求 Word 时通过[学术文档](../academic-documents/SKILL.md)输出实际文件。

建议的证据矩阵字段为：文献标识｜对象与设计｜主要证据｜局限｜拟支持的主张｜原文定位｜核验状态。经典文献与近期文献按问题需要共同使用，不能把某个年份前的文献一概判错。

## 交付检查与限制

核对正文编号与文后条目是否对应，关键主张是否有真实支持，所有数值是否保留正确对象和分母，未取得的材料是否被如实标识。未知引用不得静默删除编号后留下同一断言；应报告并处理受影响的论述。引用格式遵守用户或学校当前要求，格式通过不等于真实性通过。

本分支不承诺穷尽全部文献、引文真实率或文献计量指标。检索、全文获取与数据库接口取决于宿主实际能力；依赖缺失时仍可完成给定材料内的整理与写作，并准确交付可达范围。
