# 科技奖申报写作

围绕已完成成果及其证据撰写目标栏目。遵守[共享规则](../../references/shared-rules.md)和[当前要求](../../references/current-requirements.md)，根据当前主办方、奖项类别与年度模板组织文字；不把基金的未来研究叙事改写成已实现业绩。

## 输入

需要本次目标栏目、实际模板/篇幅、当前稿，以及对应成果证据。优先复用[奖项证据分支](../award-evidence/SKILL.md)的映射；用户已提供足够材料时直接开始，不重复要求完整申报包。缺失的科学结论、关键比较或效益证明会影响所依赖段落，其余已证实内容可继续整理。

## 执行

1. 绑定自然科学、技术发明、科技进步或目标奖项的实际类别，采用[栏目写作指引](references/writing-guide.md)。查明用户需要新起草、修订还是压缩；保持当前人工主稿和编辑范围。
2. 从问题—贡献—证据映射形成核心叙事。简介交代问题、成果贡献及模板要求的实际影响；核心发现/发明/创新按科学逻辑展开，各项与简介及附件对应，不按任意数量凑创新点。
3. 起草时就满足实际字段和篇幅。材料的作者、年份、单位、指标、效应方向和状态不因语言精炼改变；无法核实的占位符清楚标记，不将其混入可直接提交段落。
4. 国内外比较只使用可追溯同类材料，列清对象、时间、指标/单位与条件；用[比较表模板](templates/technology-comparison.csv)。检索交给[证据分支](../evidence-research/SKILL.md)。缺少可比证据就降低比较范围或保留待核，不能写出无依据的“国际领先”“首次”。
5. 应用和经济/社会效益依据真实证明、统计或用户已核数据。解释计算期间、范围和口径，避免跨单位或时期重复计入；第三方评价保留出处及评价对象，不把自评变成外部认证。
6. 对完成人与单位贡献仅整理已知材料，保持权属对应。需要 Word 工作稿时调用[文档分支](../academic-documents/SKILL.md)；需要展示创新关联或应用时间线时调用[科研可视化](../research-visuals/SKILL.md)。
7. 对正文进行一次相关事实和跨栏目一致性核查；较大修改或明确预审任务交[奖项审查](../award-review/SKILL.md)。普通写作不自动展开无限审稿循环。

## 输出和边界

输出目标栏目工作稿、必要比较表和仍影响主张的待核项；说明实际使用的证据定位。不得承诺获奖，不代替正式资格核验，不伪造签章/证明/效益/贡献。没有对应当期模板时可完成有证据的内容草稿，明确栏目和篇幅尚需按当期要求匹配；正式提交、发送或公开发布遵循用户授权。
