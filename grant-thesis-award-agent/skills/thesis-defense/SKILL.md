# 毕业论文答辩

先读取[共享规则](../../references/shared-rules.md)；学校当前要求参见[当前要求](../../references/current-requirements.md)。通过[演示文稿支撑](../presentation-support/SKILL.md)生成实际演示文件，通过[学术文档](../academic-documents/SKILL.md)读取论文和模板。用户仅要大纲或讲稿时直接完成该范围。

## 输入

复用用户指定的当前论文、已确定标题、关键结果表图、答辩时长、学校模板与需要强调的贡献。可以使用已知导师或评审意见准备问答。缺少非关键偏好时采用清晰的学术布局并说明；时长尚不明确时可先形成可调整的大纲，标明工作假设，不伪称符合未取得的学校要求。

## 执行

1. **抽取可讲述的研究主线。** 用真实材料回答问题为什么值得研究、采用什么设计、得到哪些关键发现、贡献何在、限制影响什么。把候选解释、未来工作和已完成证据区分，不能把基金式预期结果移入答辩成果。
2. **按时长组织。** 根据听众、时长、图表复杂度和学校要求安排页数与重点，将主要时间留给核心方法、结果及解释。背景只提供理解结果所需信息；页数、单页字数与讲稿总字数不设通用硬阈值。拟定时间分配后核对总时长，并根据实际朗读或用户语速反馈调整。
3. **建立逐页计划。** 每页明确目的、屏幕主信息、真实图表来源、演讲补充和预计时间。用有含义的页标题突出该页要传达的内容，标题结论不能超过对应证据。将细节、补充分析与可能被问到的表格放入适用的备份页。
4. **分开屏幕与讲稿。** 屏幕保留简洁要点、图表及必要注释，口头解释写在备注或独立讲稿。不要把长段讲稿复制到每页屏幕。讲稿介绍图中的比较、关键发现与局限，不逐字重复图注，也不补充论文没有的数据。
5. **制作实际演示稿。** 将逐页计划交给包内[演示文稿支撑](../presentation-support/SKILL.md)，按其真实工具输入格式生成文件。图表使用已核准源文件，裁剪或缩放不能丢失统计注释、单位和图例；需重绘且已授权时使用[科研图形](../research-visuals/SKILL.md)。基础可编辑文字与形状不等于图片内部内容可编辑。
6. **核查成品。** 核对幻灯片标题、图表、正文与讲稿的数字、对象、方法和结论一致性，检查实际页数与计划对应。使用可用渲染工具查看溢出、遮挡、图像清晰度、图例和字号；没有渲染工具时如实说明检查范围。PPTX 成功创建后才能报告已交付该格式。
7. **准备问答。** 针对研究问题、设计选择、统计、样本局限、替代解释、创新依据和后续计划提出与论文相关的问题。答案采用“直接回应＋已具备证据＋必要范围说明”，不能为流畅回答伪造额外实验。论文没有验证的问题可回答当前证据支持到哪里及需要怎样研究，不把后续计划说成已做。

## 逐页计划格式

按任务需要使用紧凑表格：页码｜目的或标题｜屏幕内容｜图表来源｜演讲重点｜预计时间。该表是内容组织模板；生成脚本输入遵循实际演示文稿支撑，不假定此表可直接运行。

## 交付与限制

按用户范围交付答辩大纲、实际 PPTX、讲稿和问答。时间建议需说明是文字估算、用户语速推算还是实际演练；未朗读计时不能声称已经实测满足时长。格式依赖不可用时可先交完整逐页大纲、讲稿和待制作说明，不把它们称为已经完成的幻灯片。

不承诺完全复刻任意学校专有模板，也不指定某个旧在线服务或模型作为必需工具。实际演示生成和页面查看依赖包内公共脚本及宿主已有运行库；不自动上传未公开论文，不替用户发送答辩材料。科学问答准备不代表正式评审意见或答辩通过保证。
