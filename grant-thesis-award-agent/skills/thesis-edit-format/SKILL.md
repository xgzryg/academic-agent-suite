# 论文修订、引文与学校格式

先读取[共享规则](../../references/shared-rules.md)及[当前要求](../../references/current-requirements.md)。本分支处理当前论文工作稿；用户原件、人工固定成品和已指定保留的内容不被旧稿或文本重建覆盖。

## 输入与任务范围

确认用户指定的当前稿、学校或学院现行模板、修改范围、导师批注、参考文献库和需保留的格式对象。相似性报告仅在用户提供或可依法取得时处理。局部改字、格式检查、全文润色、批注修订和相似性整改是不同范围，不强制收齐无关材料。

解析和写入使用[学术文档](../academic-documents/SKILL.md)，引用核验使用[证据检索](../evidence-research/SKILL.md)，审读或用户明确启用的循环使用[审读修订](../review-revision/SKILL.md)。能力以包内实际工具为准。

## 执行

1. **识别要求和对象。** 区分学校明确规范、模板实际样式、示范论文的观察值以及用户个人偏好。学校指定标准版本和特殊要求优先落实；查到新版标准元数据不等于取得全文，也不代表学校已采用该版。不得自称逐条实现尚未核对的标准。
2. **建立修改范围。** 保留原稿，按授权更新工作副本。先定位正文、表格、图、公式、题注、交叉引用、参考文献域、页眉页脚、目录与修订信息。若同一对象有多个版本，依据内容与用户指定判断当前版本，不能只按文件名或修改时间选择。
3. **学术润色。** 修改错误和不清楚的语句，压缩重复、理顺逻辑、统一术语，保留作者立场与必要限定。数字、单位、样本、物种、疾病定义、方向、统计方法和完成状态保持真实。用户要求语言润色时不擅自补实验、换分析或扩充论点。
4. **处理批注。** 提取批注文字与可获得的定位，逐条记录决定、修改位置、实际改动和未解决事项。工具若只提供段落上下文，不将其当作精确选区；跨段批注需人工或模型结合原稿确认范围。批注要求与科学事实冲突时说明依据，不能为“完成全部批注”而伪造事实。
5. **审计引用。** 分别检查文献身份、论断支撑、字段完整性和最终格式；正文与文后引用对应，编号或作者年份变化要一致。未知条目保持待核验，不能默认已验证，不能猜补题名作者，也不能静默删掉引用号后保留原断言。早期经典文献不因年份旧直接判错。
6. **解释相似性报告。** 定位直接引语、引用不足、自我重用、方法固定表达及实质复制等具体问题，依据理解修订并保留必要来源。需要引用或明确引语时正确处理，不能仅替换同义词以掩盖借用。检测器分数不等于作者身份或原创性结论，不设置连续多少字即“安全”的规则。
7. **执行文档修改。** 按公共文档工具实际支持的精确定位范围操作。不能通过清空整段 runs 再写入文字保留“表面样式”，也不能将复杂 Word 全量转成纯文本后宣称原格式不变。涉及跨 run 文本、上下标、域、图像或公式且现有工具无法保真时，保留原对象，输出准确的定位修改建议或使用已确认支持的原生编辑工具；如实说明未直接落入文档的修改。
8. **落实学校格式。** 校对标题层级、段落、页边距、字体、表图、题注、目录、页码和参考文献等实际适用项。新建基础 DOCX 与复刻指定模板是不同任务，基础生成器不自动保证后者。样式解析只能给出结构观察，最终排版须实际渲染查看。

## 交付与验证范围

按授权范围交付工作稿或实际 DOCX，必要时附修改对照、批注处理记录、引用待核验项和格式问题。用户只要局部修订时不强制附录、全篇大纲或额外图表。保留可复用的当前编辑源；若人工固定成品与脚本不能完全互相复现，说明具体差异，不从旧脚本覆盖。

检查实际修改涉及的数字与引用、复杂对象是否仍在、批注决定是否与修改对应，以及已渲染页面是否有截断、错位或错误页码。未渲染时准确称为结构或内容检查，不能称逐页排版通过。没有可用排版引擎时交付可验证范围并说明页面检查尚未完成。

本分支不承诺查重率、AIGC 检测器结果或盲审通过。实际 DOCX 编辑和渲染依赖宿主已有库和工具；不自动安装环境，不以技能描述替代运行证据。
