# 研究内容、目标与方案

先读[共享规则](../../references/shared-rules.md)和[当前要求](../../references/current-requirements.md)。根据当前科学问题、项目类型和研究范式设计，不按旧申请书栏目机械排版。

## 最小输入

优先读取中心科学问题、作者摘要/计划、现有研究基础、可用对象/数据/平台、执行期限和官方模板。识别任务是方案论证、模块整理、现有稿修改，还是技术路线内容设计。

缺少影响研究有效性的关键信息时，指出具体依赖；可继续先整理已知问题、已有目标和模块关系。不要自行补出实验条件、伦理批准、样本量或数据可得性。

## 工作步骤

1. **区分四层。** 科学问题回答尚未理解什么；目标说明希望查明或达到什么；内容明确开展哪些研究；方案说明用什么设计和证据回答问题。避免四层重复同一句话。
2. **界定研究范围。** 标明研究对象、主要条件/时间范围、比较对象、主要指标或评价标准。既有项目内的子课题沿用已确认分工和边界，不替其他工作包承诺结果。
3. **设计模块关系。** 根据问题实际需要组织并行、递进或支撑模块。对依赖前序结果的模块，明确需要何种输入；分析前序零结果或方法失败是否使后续无法开展，必要时提出可保留科学价值的替代方向。
4. **展开模块方案。** 每模块至少说明目的、依据、研究对象或数据、核心方法、比较/对照、指标、分析解释和与下一模块的关系。只展开本项目真正需要的技术细节。
5. **按研究范式补足。**
   - 实验研究：独立实验单位、适用对照、重复、随机化/盲法、主要观测与排除原则；不把技术重复当生物重复。
   - 观察/临床研究：研究设计、对象与时间、暴露/结局、选择与混杂、缺失、偏倚及适用伦理；不把相关性默认写成因果。
   - 计算/模型研究：数据来源、训练/验证划分、基准或对照、信息泄漏、泛化评价和算力资源。
   - 方法/理论研究：假设和适用条件、比较对象、推导或验证路径、评价指标与局限。
6. **审查分析依据。** 将方法选择与问题、数据类型和主要指标对应。样本量或精度依据缺失时列出所需假设；若用户要求计算，再按授权范围、实际数据和工具处理，不从同类示例移入参数。
7. **写预期与风险。** 预期结果说明可能获得的知识、模型或证据，不保证支持原假说。仅列实际关键风险、识别方式、受影响目标和可行备选；不要为每一步强凑三层风险防御。
8. **编排与图示。** 将内容映射到当前模板；需要图时，向[科研图形](../research-visuals/SKILL.md)交付节点、边、模块、判断点、并行/依赖及计划状态。图中路线须与文字真实一致。
9. **完成对照核查。** 确认每个目标有研究内容，每个模块有回答问题的证据方法，图与文字没有遗漏或多余承诺，工作量与期限/资源相符。

## 模块工作格式

按需要填写，可直接作为修改提纲而无需新增文件：

| 项目 | 内容 |
| --- | --- |
| 对应科学问题/目标 | 本模块要回答或实现的内容 |
| 依据与现有基础 | 已核实证据及来源 |
| 对象/数据与比较 | 研究单位、资料范围、对照和条件 |
| 核心方法与指标 | 如何获取能回答问题的证据 |
| 分析与解释 | 如何比较、验证，结果的不同可能解释 |
| 依赖与资源 | 输入来自何处，条件是否落实 |
| 预期科学产出 | 可获得何种知识或资源 |
| 关键风险与备选 | 哪个失败将改变后续工作，以及调整方式 |

## 交付与后续

输出研究目标/模块与方案的工作文本、修改说明、关键待定信息和需要的路线图内容。可把资源缺口交给[研究基础与可行性](../grant-feasibility/SKILL.md)，把确认的模块、依赖和时间交给[创新与年度计划](../grant-innovation-schedule/SKILL.md)。

适用2026国自然时，以辅助结构与方案论证、修改作者稿为主，不输出自称可直接提交的AI生成整份申请书。若其他机构和年度允许起草工作初稿，应保持证据状态和作者核实要求，不迁移国自然限制为其他机构的规则。

## 不可替代的判断

不强制3–4个模块、每模块论文数量、预实验完成百分比或一套通用生物医学方案。方法细节需要可靠来源与场景支持；需要领域专业资质才能确认的执行参数不应包装成已核验事实。科研任务是否获伦理/机构批准以真实文件为准。
