# 证据整理与成果状态

自然科学类以重要科学发现、支撑论著和学术评价为主；技术发明类以原创技术、实现、知识产权及性能证据为主；科技进步类以技术创新、实施推广及可核算效益为主。这是内容组织方法，具体栏目、名称和资格由目标主办方当期文件决定。

每个证明至少能定位到实际文件与页/节/表、材料日期和适用对象。技术指标还需要单位、测试对象和条件；经济数据还需要期间、地域/单位范围、基数、口径与证明。材料只是用户陈述时应标作用户提供待核，不能标为已经第三方认证。

建议状态为：已从原件核实、用户说明待证、部分支持、缺少材料、存在冲突。状态描述具体支持程度，不机械评分。缺项不等于成果不存在；冲突需列明两处信息与影响，避免自行择优。

归纳独立贡献时，保持问题、方法新增点、结果和意义的层次清楚。两条创新若依赖同一科学主张，仅描述层级不同，应合理整合；一份证据若同时支撑多项贡献，分别说明支持的内容。贡献编号只为正文与附件衔接，不新增冻结编号或哈希机制。

经济效益的计算区分累计/当期、毛值/净增、直接/间接，以及多应用单位之间是否重叠。客观评价核对评价主体、对象、出处、日期和原意，转述不能扩大范围。证明文件缺少签章时可记录当前状态、整理需补字段，不能制作冒充已签发原件。
