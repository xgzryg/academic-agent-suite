# 科技奖成果与证据整理

将实际成果组织为可追溯的贡献与证据对应表，为简介、核心创新和附件栏目提供共同依据。先遵守[共享规则](../../references/shared-rules.md)，涉及奖项要求时读取[当前要求与核查方式](../../references/current-requirements.md)。主办方、奖项类型、年度与模板不同，不能共用固定字数、附件额度或成果期限。

## 输入

复用已有主办方/层级、自然科学或技术发明或科技进步等类型、申报年份、模板及当前工作稿；读取本次相关论文、专利、验收、应用证明、评价、贡献与权属材料。仅整理某一项创新时，不要求先提交所有申报材料。模板缺失仍可做内容整理，但资格、栏目限额与最终合规结论保留待核。

## 执行

1. 判断材料是原始事实、第三方证据、用户说明还是供借鉴的案例。按[证据处理说明](references/evidence-method.md)读取实际附件；文档解析使用[文档分支](../academic-documents/SKILL.md)。未读、缺页、截图乱码标明具体范围，必要时看页，不能把已上传当作已完整阅读。
2. 以实际成果为单位记录名称、完成/应用日期、来源定位、状态与主体。论文和专利分别核对发表/授权状态；申请号不等同授权事实，研究计划不等同完成事实。
3. 按问题与新增贡献归纳发现/发明/创新。每项说明解决的具体问题、与已有工作的差别和适用范围，再关联证明；不要单凭论文或专利数量推导创新性。
4. 使用[证据映射模板](templates/award-evidence.csv)建立普通行表。已存在合适项目表时直接更新授权工作表，不另建重复索引。多份证据支撑同一贡献可分行，不能把一份局部证据扩展为支持整项成果。
5. 核对贡献主体、完成单位与知识产权关系。保持作者、发明人、完成人、应用单位这些角色的实际区分；未有材料支持的归属不推断。将不足归入受影响栏目或主张，给最少必要待补项。
6. 交给[奖项写作](../award-writing/SKILL.md)或[奖项审查](../award-review/SKILL.md)，带上当前模板、主稿、贡献编号与证据定位。若需要外部同类比较，调用[文献与证据分支](../evidence-research/SKILL.md)，遵守实际授权的检索范围。

## 输出和边界

交付成果清单、贡献—证据—栏目映射、附件缺口与实际已读范围。`award-evidence.csv` 是工作资料，不代表主办方资格认可。不得虚构论文、授权号、应用证明、第三方评价、签章或经济效益；不得改动受保护原件。缺少主办方现行要求时明确具体未核项，继续不依赖这些要求的整理工作。
