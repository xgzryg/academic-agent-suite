# 运行依赖与可用能力

本包内置运行指引、功能分支、选定引擎源代码与辅助脚本。包内路径相对定位，可以整体复制到新的安装目录。外部运行时和服务由宿主或用户环境提供；“独立安装文件夹”不表示内置所有软件。

| 能力 | 所需条件 | 缺少时的处理 |
| --- | --- | --- |
| 材料理解、故事板和演讲稿撰写 | 支持读取本地材料的 AI 宿主与模型 | 可以提供流程/草案，但不能称已读取不可访问的文件 |
| 原生 PPTX 生成、模板分析、SVG 对象转换 | Python、python-pptx、Pillow；所需间接库随公共包环境提供 | 先发现现有环境；不能执行时保留已完成内容，说明未生成文件 |
| 模板中的原生图表工作簿更新 | 上述条件及 openpyxl | 不把旧图表数字描述为已更新 |
| Markdown/HTML 讲稿从 JSON 导出 | Python 标准库 | 缺少 Python 时由宿主按实际工具处理，不能伪造运行记录 |
| 从实际 PPTX 读取讲稿、核对备注 | Python、python-pptx | 保留缺项或改用宿主可用的真实读取方式 |
| Word 读取、Word 讲稿 | python-docx；复杂 XML 修改涉及 lxml | 可交付已完成的 Markdown/HTML，并说明 Word 未导出 |
| PDF 文本与页码提取 | pypdf | 可用宿主实际 PDF 阅读能力；不能把提取失败当空白页 |
| PDF 页面 PNG 渲染 | pypdfium2、Pillow | 使用其他已有渲染器或说明未查看对应页面 |
| 最终 PPTX 的 PNG/PDF 导出 | Windows + Microsoft PowerPoint + PowerShell 可使用包内脚本 | 其他系统使用实际存在的 Office/LibreOffice 路线；没有渲染器则明确未完成视觉核查 |
| 离线 HTML 手册与讲稿 | 支持现代 JavaScript 的浏览器 | 手册正文保持可阅读；讲稿交互需要脚本支持 |
| PubMed 文献检索与元数据取回 | Python 标准库、网络及 NCBI 服务可访问 | 整理已有资料与检索式；区分失败、部分返回和零命中 |
| 其他数据库、联网查证、图片理解 | 宿主实际提供的搜索/浏览/视觉工具 | 只承诺实际可用范围；不会自动安装第三方连接器 |
| 真实独立子 agent 审改 | 宿主提供真实委派能力，且任务已明确开启 | 可说明改用单 agent 审查，不伪装独立多人评审 |
| 旁白、特殊动画或自动播放 | 用户明确要求、对应媒体/工具和实际播放验证 | 默认关闭；不承诺跨平台保真，也不自动订阅语音服务 |

## Python 环境

建议使用维护中的 Python 3.10 或更新版本；本包不自动创建环境。典型所需公共库为：

```text
python-pptx
Pillow
python-docx
pypdf
pypdfium2
openpyxl
```

基础原生路线只需相应基础库；无需为一次文字修订安装全部可选组件。SVG 原生转换默认不会为整页栅格化而要求 CairoSVG；特殊媒体处理按实际代码路径决定。Node.js 不是本包上述核心命令的必要条件。

根目录的 `requirements.txt` 按功能注释列出基础和可选公共库。主动执行 `python -m pip install -r requirements.txt` 会安装其中所有已列出的库；仅需基础路线时可以只安装 `python-pptx Pillow`。本包安装脚本不会代为执行 pip。

在终端先检查所用 Python 的导入情况；不要根据另一套 Python 已装了库就认定当前命令可用。需要安装公共库时，使用用户确认的环境和网络条件。具体安装示例见 [INSTALL.md](../INSTALL.md)。

## Office、字体和渲染

包内 Windows 导出脚本通过实际 PowerPoint 打开指定 PPTX 并导出，不能在没有 PowerPoint 的机器上独立工作。其他渲染器需要宿主按当前环境选择；本包没有一键安装 Office 或通用云转换服务。

脚本生成的对象尺寸与文字检查用于发现具体问题，不能保证真实字体、换行和全部媒体显示正确。最终视觉核查必须基于实际交付 PPTX 的渲染。字体替换、某些 Office 版本差异、SmartArt、OLE 和媒体效果应按当前文件验证。

## 网络与材料

使用用户提供的本地材料、生成基础 PPTX 与导出离线讲稿不必依赖外部内容服务，但 AI 宿主自身是否离线取决于它的运行方式。检索 PubMed、核验现行规定、访问网页和调用外部图像/语音服务需要网络。不可把本包有本地脚本等同于模型处理也完全离线。

任务材料和成果保存在用户项目目录；包不包含私人账户、API 密钥、登录态或开发机材料路径。使用外部服务的内容范围遵循实际授权，病例及未发表材料不因模板功能而自动外传。
