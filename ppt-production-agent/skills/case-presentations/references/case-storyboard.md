# 病例故事线与教学讨论

## 以事件和决策组织内容

可依病例特点组合：病例目的与必要背景 → 首次表现 → 关键检查和病程 → 当时的诊断/鉴别判断 → 处理选择及依据 → 后续变化 → 结局/随访 → 复盘与启示。不同病例不必套用同一栏目数或页数。

每个重要决策点说明三个层次：

- **当时可见事实**：症状、体征、检查、图像或既往资料。
- **当时采取的行动**：实际记录中的进一步检查、治疗、观察或转诊。
- **本次复盘**：哪些证据支持该选择，哪些信息尚缺，是否存在其他合理解释。

复盘不能倒置时间，也不能把“建议考虑”写成病例已经执行的措施。单例提示的线索与普遍有效性分开，病例转归本身不证明一种处理方式适用于所有人群。

## 视觉选择

| 内容 | 适合表达 | 需要保持的事实 |
|---|---|---|
| 多次就诊/处理 | 时间线或阶段表 | 顺序、关键间隔、日期含义 |
| 检验随时间变化 | 表格或有真实数据的趋势图 | 单位、时间点、缺失值、参考范围 |
| 影像/病理 | 原图、正确标记、前后对照 | 患者/部位、时间、左右侧、模态、比例尺 |
| 鉴别诊断 | 证据支持/不支持/尚缺的比较表 | 证据强度和不确定状态 |
| 决策过程 | 流程图或分支图 | 当时条件、执行步骤、备选项 |

如果日期需要脱敏，可在不影响教学问题的前提下改用相对时间，并确保保留实际间隔。若精确年龄、时间或地域关系对该病例的科学意义重要，先判断可行的表达方式，而不是随意删改。

一页可以有足够说明帮助讲者解读，但应围绕一个判断或阶段展开。检验大表和多图拼图无法投影阅读时，选取与问题相关的片段，保留完整材料作为备用。

## 讲稿与互动

讲稿让听众按事件推进理解病例，可在关键决策处暂停并提出“基于此时的信息，还需要什么”“哪些解释仍成立”等问题。讨论问题必须以当时信息为前提；若设计逐步揭晓，不在前页备注以外的可见区域提前泄露后续答案。

需要解释新的医学概念或比较诊疗策略时，依据经过核验、适用于该情境的资料。用户原始记录中未出现的处理，可以明确作为回顾性讨论或待验证建议，不能改写病例原文。

结束时概括本例能支持的教学要点、真实不确定性和适用条件；不要仅因排版需要构造“成功治疗”“完整治愈”或确定性因果结论。
