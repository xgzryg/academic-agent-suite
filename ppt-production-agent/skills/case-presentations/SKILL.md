# 病例汇报与讨论

围绕病例经过、临床决策和教学启示组织演示。读[共享规则](../../references/shared-rules.md)及[病例故事线](references/case-storyboard.md)。本分支处理材料表达与讨论，不能把未经核实的生成内容当作患者记录或实际诊疗事实。

## 从真实材料开始

读取本次病例文字、检查/检验、影像/病理、处理记录、结局和图片说明。确认材料是否属于同一病例及正确时间；提取本次主题、听众、时长、模板与需要强调的决策问题。

保留事件顺序与必要的时间间隔。图片编号需对应真实患者/病例编号、检查时间、模态、左右侧或部位和说明；不同来源的相似图不能自动互换。无法确定对应关系时标出待核，而不是凭视觉相似猜测。

去除与教学目的无关的可识别信息，并核对截图中可见的姓名、编号、日期等字段。用户允许本地制作不等于允许把原始病例上传外部服务。示范病例若由模型构造，应显著标为教学虚构案例，不能混入用户提供的真实病例。

## 调度

1. 调用[内容策划](../presentation-planning/SKILL.md)建立时间线和逐页故事板，围绕发生了什么、当时知道什么、为何采取该处理、结果如何和可得到什么启示。
2. 调用[图表与证据](../figures-and-evidence/SKILL.md)，处理原图、趋势表、时间线和诊断/处理流程。保留单位、参考范围、比例尺和关键信息；缺失的体征、检查、剂量、时间或疗效不能补造。
3. 调用[原生PPTX](../pptx-native/SKILL.md)制作可编辑页面。医学影像作为实际图片保留，不通过生成图重建患者影像；示意图清楚标识，不替代真实发现。
4. 需要口语稿和讲者备注时调用[演讲稿](../speech-writing/SKILL.md)。稿件按实际页序串联事件和决策，区分“当时的判断”与“事后复盘”，避免用后来信息解释成当时已经知道。
5. 需要鉴别诊断讨论、讲者备问或教学互动时调用[问答演练](../qa-rehearsal/SKILL.md)，传递资料可见范围与未确定事项。实际诊疗建议或新指南比较按用户任务和证据条件另行核验。

## 缺口与确认

重要缺项应具体到影响：如缺少检查时间影响病程顺序，缺少病理结论影响诊断页，缺少疗效记录影响结局表述。可以先完成不依赖缺项的内容，保留清楚的待补标记；不能用空泛“完善资料”代替说明。

用户已经明确确认病例事实后不因页面排版重复问同一问题。发现事实互相矛盾、病例/图片身份不明或用户希望改动诊断结论时，需要把相应依赖步骤停在真实核实点，继续其他已授权制作。不得为叙事顺畅修改事实。

## 完成依据

核对时间线、图片身份、数值与单位、处理顺序、结局和讲稿的一致性；真实缺失仍标缺失，推断与事实分开。检查可见页面和备注是否残留可识别信息或模板旧病例。以实际渲染确认影像标签、检验表和流程图可读，清楚列出未核对内容。
