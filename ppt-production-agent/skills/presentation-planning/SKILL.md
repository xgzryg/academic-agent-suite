# 策划与故事板

用于新建整套演示、从长材料提炼内容或改变受众/时长。先读取[共享规则](../../references/shared-rules.md)。

1. 复用用户已给的信息，核对目的、听众基础、场景、总时长、问答预留、语言、格式、模板和必讲内容。缺少影响正确性的事实时说明；次要视觉偏好可以合理选择。
2. 读取当前源材料并识别研究/项目事实、范文和模板。为需要展示的主张找证据位置，对读不到的页或图明确记录。不要默认外部搜索或全文翻译。
3. 根据任务进入学术、教学、病例或商务分支。安排开场问题、逻辑推进、关键证据、结论/请求和备份页，不把所有任务套成论文结构。
4. 给每页稳定 ID，安排标题消息、屏幕要点、图表/表格、来源、口语稿和用时。页数由活动要求和内容决定，不能靠空页满足配额。
5. 用户要求先看大纲时在该处等待；已确认或明确自动完成且信息足够时继续生成。重大取舍涉及删除结论、改变方案或省略必需结果时交回用户判断。

生产故事板参考[格式](../../references/storyboard-format.md)。创建演示用[原生分支](../pptx-native/SKILL.md)或[高级引擎](../pptx-engine/SKILL.md)，并按需进入[演讲稿](../speech-writing/SKILL.md)。输入是既有 PPTX 时改走[编辑](../presentation-editing/SKILL.md)，保留其人工修改。

交付故事板必须有可追踪的素材和具体可讲内容，不能以“插入相关图片”等空指令冒充已完成页面。必要的素材缺项可在任务中列出，不把占位图当真实图。
