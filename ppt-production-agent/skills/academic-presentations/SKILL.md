# 学术汇报与答辩

把研究材料组织成适合指定听众和时长的学术表达。沿用用户已选主角色及输出范围；请求一页修改、提纲或讲稿时，不扩大为整套答辩制作。

先读包内[共享规则](../../references/shared-rules.md)。按实际任务读取下表对应参考；一次任务通常只需一个主要流程。

| 任务 | 阅读 | 内容选择的中心 |
|---|---|---|
| 单篇/多篇文献汇报、Journal Club | [journal-club.md](references/journal-club.md) | 研究问题、证据链与可成立的解释 |
| 组会进展、中期研究汇报、学术会议口头报告 | [research-and-conference.md](references/research-and-conference.md) | 当前研究状态、主要贡献与听众需要的判断 |
| 本科/硕士/博士毕业答辩、预答辩 | [thesis-defense.md](references/thesis-defense.md) | 已完成研究、研究间联系和个人贡献 |
| 开题、研究计划论证 | [proposal-defense.md](references/proposal-defense.md) | 值得研究的问题、可行路线与可检验目标 |

## 调度与实际制作

1. 读取当前论文/报告/申请书、已有PPT和可用图表，明确本次版本、可见范围与研究状态。从现有信息取得主题、受众、口头/问答时长、语言、画幅和模板要求；核心材料或目标存在歧义时只问影响工作的缺项。
2. 调用[内容策划](../presentation-planning/SKILL.md)建立研究主线和逐页故事板。按结论的重要性与证据复杂度分配时间，保留适量背景；不按论文章节等比例压缩，不凑固定页数。
3. 调用[图表与证据](../figures-and-evidence/SKILL.md)，将原文图号、面板、页码、文件和该页主张对应起来。原始图片、概念示意、从真实数据重绘和待补占位应能区分。模板中的图和示例结果不能自动变成当前研究材料。
4. 调用[原生PPTX](../pptx-native/SKILL.md)或主agent已选择的制作路径生成可编辑文件。细节说明移入备注或备用页；必要面板可拆页放大，保留图例、单位、方向、样本与对照标识。
5. 需要逐字稿、讲者备注或时长适配时调用[演讲稿](../speech-writing/SKILL.md)。稿件跟随最终页序和实际图表，区分主报告时间与Q&A时间；用过渡串起研究问题、方法、结果及解释。
6. 需要备问、预答辩或互动演练时调用[问答演练](../qa-rehearsal/SKILL.md)。提供本流程的评价重点、真实材料范围和证据索引；不因“预答辩”一词自动开启多轮真实子agent循环。

## 学术信息边界

- 文献作者的发现、汇报者自己的结果、计划开展的工作、解释和示例分开表达。开题/申请中的预期结果不能写成已完成成果。
- 读取不完整时标明缺失的正文、图表或补充材料，允许按现有范围产出草案；未经阅读不能称为“全文精读完成”。重要证据缺口不能用常识性段落或虚构引用填满。
- 图像与主张须逐一匹配。允许对同一图进行说明性裁分/标记，但不改动原实验数据、误差线、比例尺和结论方向；只有截图时不假造精确数值重绘。
- 统计问题按真实研究设计适用。不得仅为了题库覆盖改变用户已确定的分析、增算未授权实验，或把不相关的方法学检查列成缺陷。
- 需要当前创新对比、期刊指标、项目要求或会议规则时核验适用来源和年份；未检索时不写“最新”“首次”或精确指标。期刊指标不是研究质量替代品。
- 用户已要求自动完成且输入充分时，继续完成制作与验证。用户明确要求先看大纲/逐步确认时保留该停止点；新增科学结论、修改研究设计或更换受保护成品不由模板习惯代替用户决定。

## 完成依据

交付符合本次范围的故事板/PPTX/讲稿/备用页与必要来源索引。核对研究状态、关键数值、目录、页序、讲稿和图表引用的一致性；实际渲染后处理妨碍阅读的遮挡、溢出和小字。未得到的图、未核验的引用或无法验证的效果清楚列在待补事项，不混入已完成结论。
