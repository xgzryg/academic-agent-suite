# 文献汇报

## 从文章到汇报

先确认汇报对象是单篇论文、若干相互关联的论文，还是围绕一个问题比较研究。阅读实际提供的正文、关键图表、方法和附录；记录尚不可见的范围。多篇研究不能混用样本、图号、实验条件与结论。

以一个清楚的研究问题串起内容：已有认识与缺口 → 作者如何设计研究 → 哪些结果回答哪些问题 → 结论能成立到什么程度 → 对本组研究或听众有什么可借鉴之处。题目、期刊、作者、时间只需支持文章识别；不以影响因子代替研究价值解释。

在故事板中为每个结果页说明：

- 本页要回答的子问题和可支持的主要判断。
- 图表的真实文件、原图号/面板、来源页；该图是原图、裁分或重绘。
- 听众需要先理解的分组、横纵轴、单位、对照和统计标记。
- 讲解顺序与结论边界；对后续研究问题的自然过渡。

没有必要把全文每张图放上主报告。按重要性选取时，说明本次汇报覆盖范围，把相关方法细节和必要补图放备用页。图表密集时按研究问题拆页，不能缩小到无法判断关键差异。

## 讲稿与批判性理解

逐页口语内容应讲清“为什么看这张图—怎么读—能得出什么—还不能说明什么”，避免先背结论再一口气报数。不要为每页机械添加局限性；仅在它影响解释或后续判断时说明。

需要备问时，从下列方向选择文章实际存在的问题：

1. 问题定位及与先驱研究的增量。
2. 方法、假设和对照是否回答研究问题。
3. 效应大小、数据量、稳健性与可重复性。
4. 替代解释、偏倚和因果解释的条件。
5. 适用人群、场景与失败边界。
6. 对学科、实践或后续研究的贡献。

问题须针对实验、观测、理论、仿真、质性或混合方法的实际范式。答复以直接回应、论文中的可定位证据和必要的独立评价组成；需要外部对照文献时先核验，不虚构引用或作者立场。

开放讨论可另准备方法替换、应用条件、后续研究和跨学科问题，并给不同论点及依据。定性准备优先级不等于真实被问概率；题数与长短答复按问答时长决定。

## 容易出现的实际错误

- 将模板的Graphical Abstract、学校标识或旧文章指标遗留在新汇报中。
- 裁掉面板字母、图例、样本量或对照标识，使结论失去条件。
- 把作者假说、补充分析或汇报者推测讲成已经证明的发现。
- 没有读取附录却编出实验细节，或用短摘要冒充全文证据。
- 为“批判性”而制造论文没有的缺陷。材料正确且证据充分时，应直接说明成立的理由。
