# 开题与研究计划论证

## 保持计划状态

开题的目标是说明问题值得研究、方案能回答问题、研究者与资源具备可行性。它不要求已有完整结果，也不能把预期效果写成完成发现。

从当前开题报告中区分：已有文献事实、本人预研究/预实验、研究假设或命题、拟采用方案、预期成果与时间安排。图中使用的模拟数值或示意结果要明确标为示例；不要用示意图伪装预实验。

## 建立研究逻辑

按实际研究需要组合这些内容：

1. 已有认识、未解决的问题和本课题切入点。
2. 可清楚表述的核心问题，以及对应假设、命题或设计目标。
3. 研究内容之间的关系及其与目标的对应。
4. 方法选择、技术路线、数据来源与关键判断条件。
5. 预研究证据、已掌握能力、关键资源与可能瓶颈。
6. 时间计划、阶段成果和合理的替代路径。
7. 预期贡献及研究范围。

理论、仿真、实验、观测和质性研究采用不同方法评价标准。研究计划应与用户实际学制、进度、资源和学校要求匹配，不套用固定几年或固定项目规模。

技术路线图要表达输入、主要操作、判断与输出的关系，不只是连续的名词方框。时间图中的任务依赖和资源约束来自真实计划；尚未确定的参数标注待定并说明它会影响什么。

## 讲稿与开题问答

讲稿应使听众理解“为什么采用这条路线”。预实验页说明它已支持什么、仍不能确定什么；未来实验用计划时态。进度安排不能承诺成功结果或某等级论文。

备问重点为问题凝练、选题边界、理论框架、关键方法、创新性、预研究充分性、资源可用性、技术瓶颈、假说被证伪的价值和时间规划。可按需加入与导师/课题组的关系、独立思考和伦理设计。

若材料确实缺少关键资源或方法依据，说明其影响，并提出能由用户或后续工作解决的具体缺项。不为了完成PPT自行承诺合作平台、增加不存在的预研究或扩展研究范围。

用户明确要求先确认研究方案或核心标签时，在该处等待；一般版式、口语过渡及已同意内容的展开可继续完成。确认后的方案不因调用另一个包内技能而重复审批。
