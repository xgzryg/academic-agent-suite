# 毕业答辩与预答辩

## 理解学位论文整体贡献

读取实际可得的摘要、主要章节、方法、图表、参考文献和附录，识别研究之间是并列、递进、验证还是应用关系。了解学位层次和院系的实际要求；本科、硕士、博士的材料复杂度与答辩侧重点不能机械等同。

先形成一条能够贯穿全文的回答：研究什么问题、为什么重要、本人做了什么、得到了哪些可靠结论、贡献在哪里。选择能支撑这条回答的章节和图表，不按章节平均分配页数。

可用结构：研究背景与问题 → 研究目标及总体路线 → 相互衔接的研究内容和核心证据 → 主要贡献 → 必要局限与后续研究。具体顺序由论文逻辑与答辩要求决定。创新点、结论和对应证据须能够相互定位。

材料中的合作成果、个人贡献与导师/团队支持分开。只能依据用户资料表述个人承担的工作；已经发表的论文与学位论文整体扩展也要讲清，不自动把共同作者成果归为独立完成。

## Speaker Notes

口语稿围绕证据链展开，并交代研究之间的过渡。复杂图要有读图顺序；关键技术可以先讲直观目的，再解释必要细节。预留指图和停顿，不让背景挤占主要贡献时间。

需要缩短答辩时，优先保留核心问题、研究之间联系、贡献及关键证据。方法参数、额外推导和次要结果移入备用页。不能删去会改变结论意义的限制条件来换取流畅。

## 备问方向

按实际论文选择问题并调整梯度：

- 选题与研究范围为何合理；与重要先驱工作的区别。
- 概念、理论框架、文献综述和研究命题是否贯通。
- 方法为何适用，关键假设、对照与统计报告是否支撑结论。
- 证据强度、负结果、稳健性和替代解释。
- 创新层次、独立工作及合作贡献。
- 适用边界、推广条件、失败情境。
- 学科贡献与可执行的后续研究。

技术推导、关键方法原理、论文题目用语和伦理事项仅在适用时加入。不要机械要求每种研究都有功效分析、随机对照或多重检验校正。

每个推荐答复包含直接回应、真实论文证据及必要边界；较长备答可配现场短答。证据点写真实章节/图号/数据位置。需要解释未完成的工作时承认现状并提出可行处理，不能改写成已经完成。

用户明确要求模拟答辩时，按问答分支进行逐题练习。准备问题清单本身不授权无限循环、创建多个真实评委进程或自动大幅修改学位论文。
