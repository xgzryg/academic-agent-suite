# 项目与人才答辩

## 按评价对象和阶段分流

| 模式 | 应回答的问题 | 核心材料 |
|---|---|---|
| 项目申请 | 问题是否重要、方案是否创新且可执行、团队是否具备条件 | 申请书、当前项目指南、研究基础、预算、进度与资源 |
| 人才申请 | 申请人已形成什么独立贡献、具有什么发展潜力、未来方向是否清楚 | 真实履历、代表成果、贡献说明、未来计划与依托条件 |
| 项目中期 | 与原目标相比完成了什么、差距为何出现、如何推进 | 批准计划、阶段结果、资源/经费情况与调整说明 |
| 项目结题 | 哪些目标达成、证据何在、哪些未达成、成果与价值是什么 | 原任务书、实际成果、支撑数据、经费与交付记录 |

从已有材料确认类型和当前阶段。不要把人才答辩改成项目技术细节堆砌，也不要把结题汇报写成未来愿景。

## 项目导向

组织科学问题或项目需求、现有不足、核心假说/目标、研究内容、技术路线、前期基础、进度与必要风险处理、预期贡献。预算、人员、设备或合作条件只在它们影响可行性或实际评审要求时展开。

每一项研究内容应对得上一个目标，说明投入与阶段输出。预实验支撑的是可行性或假说合理性，不能当作整个项目已经证实。对于真实瓶颈给出可行替代路径；没有证据时不承诺关键技术、合作设备或团队能力。

## 人才导向

以申请人形成的研究主线和代表贡献为中心，说明贡献的证据、个人承担部分、学术/技术影响、未来方向和环境支持。优先讲清有分量的贡献，不以大量论文封面、期刊指标或头衔替代能力论证。

共同成果、团队成果与本人贡献分开。推荐信、任职、学术荣誉、引用数据和排名不允许根据合理猜测补齐。需要对竞争研究比较时，使用核验后的公开事实并保持公正。

## 讲稿与备问

项目申请讲稿突出为什么值得做、如何做和为什么能完成；人才申请突出本人贡献与发展方向；中期/结题使用实际完成状态和与原计划的比较。口头时长和提问时间分开估计。

按类型选择问题：科学问题、创新层次、目标范围、方法、预实验、关键资源、进度/经费、Plan B、负结果、合作分工、已有项目关系与预期成果。定性准备优先级不作真实被问概率。

答复可给直接判断、申请书/成果中的证据和必要补充说明。对于尚未做的实验或尚未落实的合作，用计划或待补状态；不能为了答得完整声称已经落实。

## 当前规则与授权

具体基金/人才计划的年龄、资格、资助年限、申报要求和评审侧重点，应以本次适用年度的官方材料为准。没有核验时不把历史经验写成现行规则。主agent可继续完成不依赖这些信息的版式和已确定内容，暂停依赖未决资格/方案的结论。

“修改答辩PPT”通常不等于获准重写研究方案、变更预算或改任务书。发现实质冲突时说明影响；按用户明确授权更新对应材料，并保持当前PPT、讲稿和相关索引一致。
