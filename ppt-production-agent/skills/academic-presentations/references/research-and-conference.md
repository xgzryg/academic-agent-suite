# 科研进展与学术会议

## 先区分交流目标

| 场景 | 主线 | 听众需要的结果 |
|---|---|---|
| 组会/内部进展 | 上次问题 → 本次完成 → 结果与解释 → 当前卡点 → 下一步 | 理解进展、讨论方法或作出资源决定 |
| 阶段考核/研究中期 | 原目标 → 已完成工作 → 与计划差距 → 原因与调整 → 剩余路线 | 判断是否按目标推进、调整是否可执行 |
| 学术会议口头报告 | 问题与缺口 → 核心方法 → 最有价值结果 → 贡献与边界 | 在有限时间内理解并记住研究贡献 |

使用当前真实研究文件与用户最后确认的结果版本。若只是编辑现有PPT，保留人工排序和内容，不从旧故事板重建覆盖。

## 内容选择

内部进展可呈现未完成、负结果和方法困难，但要说明它们对下一个决定有什么影响。按“已做、正在做、拟做”区分状态；计划中的样本、分析和实验不放入已完成结果统计。

会议报告通常只保留一个主贡献及必要证据链。口头报告限时、会议模板、参考文献/披露要求以实际通知为准。按听众知识基础决定方法细节，避免将学位论文全部章节压成密集小字。细节推导、敏感性分析、额外实验和完整参考材料可放备用页。

若展示进度比例、模型比较或阶段指标，必须有真实分母、日期和计算依据；没有数据不生成精确百分比图。“尚未完成”比推测的进度条更准确。

## 讲稿与问答

开场直接交代本次要解决或报告的问题。结果页讲出变化的实际意义；过渡说明下一项分析为什么必要。结束页回到贡献、当前结论及下一步行动，不能在最后新增此前没有支持的主张。

为组会准备方法选择和下一步取舍问题；为会议准备研究假设、关键技术、与已有方法对比、外部效度和应用条件问题。答复区分完成证据与拟补工作，不能用“我们已经做了”代替真实缺失的实验。

时长估计中保留换页、指图和问答时间。需要短版时压缩背景、次要证据或移入备用页，不能只提高假定语速使所有内容勉强塞入。
