# 页面设计与视觉统一

按用户模板、受众和显示场景确定一个样式主控。已有清楚方向或局部修改时沿用，不额外要求设计访谈。

整套视觉规划、模板适配或重设计时读取[设计方向与视觉主控](../../references/design-direction.md)，据内容选择构图并以实际 PPTX 渲染终审。

- 用标题表达本页要点，层次由字号、空间和对齐建立；装饰不得掩盖内容。不要把整篇文章缩小塞进一页。
- 以投影阅读为起点时可从标题约 30–40 pt、正文约 20–28 pt 调整；密集数据优先分步或拆页，最终以实际显示和任务要求判断，不硬套数字。
- 保持清楚的明暗对比；避免只靠红绿区分类别，图例、形状或直接标签应能辅助识别。字号、留白、比例和主题跨页一致。
- 时间线、方法流程和比较关系优先用可编辑结构表达；有真实数据时使用原生图表或定量图。图形摘要、装饰图与原始实验图的证据地位不同。
- 科研图等比显示，不裁掉轴、图例、显著性含义或比例尺；需要放大面板时保留图号和上下文。
- 模板有多套角色字体或人工强调时，先查清规则。统一配色不能等同完整美化，重建也不能假称保留原动画和数据。

生成前复用[策划](../presentation-planning/SKILL.md)的主线；生成后用[交付核查](../delivery-qa/SKILL.md)查看真实页面。只要求美化时，先固定内容，若发现事实问题单独指出并在授权范围内处理。
