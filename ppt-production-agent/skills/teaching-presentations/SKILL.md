# 教学、培训与继续教育

以学习者应理解或能完成什么为内容选择依据。先读[共享规则](../../references/shared-rules.md)，再根据目标读取相应模式：

- 建立概念、原理与操作能力的课程/培训：读[classroom.md](references/classroom.md)。
- 面向已有专业基础听众的证据、指南、技术或实践更新：读[continuing-education.md](references/continuing-education.md)。

实际听众和学习目标优先；不因资料来自论文就自动做成Journal Club，也不把继续教育重新做成从零开始的基础课。

## 工作方式

1. 从现有说明取得主题、听众基础、使用场景、学习目标、总时长、互动时间、语言、模板和可用教材/资料。只有缺项实质影响教学内容时补问；没有模板可直接采用适合投影的中性设计。
2. 调用[内容策划](../presentation-planning/SKILL.md)，把知识组织为模块和逐页故事板，说明每个模块的教学作用。按概念难度与活动所需时间分配篇幅，不为固定页数填充内容。
3. 调用[图表与证据](../figures-and-evidence/SKILL.md)，选择能帮助理解的原图、简化示意、比较表、流程图或练习。原资料来源、图号及重绘状态清楚，例题数据与真实证据分开。
4. 调用[原生PPTX](../pptx-native/SKILL.md)形成可编辑页面。允许教学型页面保留必要完整句、分层要点和解释；图表/目录页保持简洁。复杂推导可分步展开或拆页，不通过极小字号塞入全部讲义。
5. 需要讲稿、备注、提示卡或不同时长版本时调用[演讲稿](../speech-writing/SKILL.md)。备注补充解释、例子、活动指令和过渡；教学时间包括停顿、思考、讨论及反馈，不能只统计讲稿字数。
6. 需要课堂问答、随堂练习或讲者备问时调用[问答演练](../qa-rehearsal/SKILL.md)，注明任务属于教学活动或讲者练习。不要默认启动答辩式多agent审稿。

## 内容与交付要求

- 每页服务一个明确的教学重点；较高文字密度可以合理，但不直接复制整段教材或把讲稿压进画面。
- 使用教材、指南或论文时明确资料版本和可见范围。缺少关键图或最新依据时标注具体缺口；不能用似是而非的内容补齐。
- 关键数据、推荐、定义和图表具有可定位来源；术语首用时按听众需要解释，中英文缩写保持一致。
- 教学目标、页面内容、活动题目和预期学习结果应一致。题目或案例可以是明确标注的教学示例，不能伪装真实研究结果/病例。
- 现有课程修改先读当前PPT和备注；保持用户已定课程边界、语言与人工内容。用户要求先审大纲时保留该确认点；常规展开与版式改进不重复询问。
- 交付按本次需要包含PPTX、讲稿/备注、活动说明、答案或讨论要点。答案只放在讲者备注或独立讲师版时，应检查学生可见页面不会提前泄露答案。
