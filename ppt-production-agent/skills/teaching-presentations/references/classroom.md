# 课程讲授与技能培训

## 教学主线

先将主题转为可理解的学习目标，例如解释一个机制、比较两种方案、判断一个案例或完成一个操作。课程页数由目标、听众基础和授课时间决定。

常见结构可以是：为什么重要 → 概念与前提 → 原理/机制 → 代表性证据或例子 → 应用/操作 → 常见误区 → 小结与练习。只保留对本课必要的模块，不要求每一节单独成页。

定义页给出术语、关键条件及一个能帮助辨析的例子。机制/推导页分清变量或节点关系，逐步说明因果、条件或逻辑联系。操作培训页说明任务目的、实际步骤、判断标准及常见错误，界面和参数以当前可核验材料为准。

## 文字与视觉

保留能让学生看懂、讲者顺着解释的文字：标题、少量分层要点和必要解释句。主标题说明本页知识点或判断，不强求所有页都是研究结论句。

概念图、流程图和比较表应减少无关细节。需要引用教材/论文图时记录具体来源；重新绘图不意味着可以改变数量关系或取消出处。只有图像而无原始数据时，可以讲解、裁取或做明确的概念示意，不能推造数值图。

纯图表、目录、章节和总结页保持相对简洁。细节留在备注、讲义或备用页；投影无法读清的标签要放大或拆页，而非继续压小字号。

## 学习活动和讲稿

根据目标添加真正有用途的活动，例如概念辨析、短案例、预测结果、解释图表、操作演示或错误诊断。不为每页强制增加提问。

为活动说明：给学生的指令、预计时间、回答形式、讲师反馈要点。涉及正误判断时提供可解释的答案依据；开放讨论可给多种合理观点和条件。

逐页讲稿要能解释概念，而非照读屏幕。给例子、必要类比、过渡和对听众的提问提示；类比的适用边界必要时说明，避免让形象表达替代准确含义。

时长包括演示、学生思考、讨论和反馈。需要短课版时减少目标或活动，不靠假定不现实的语速缩时。用户已有授课实测时长优先于自动估算。

## 授课前核对

核对教学目标是否被覆盖、术语是否前后一致、例题和答案是否匹配、参考图与讲稿是否对应。学生版不含不应提前显示的答案；讲师版保留必要提示。发现不适合当前听众的深度时调整，而不机械堆满所有资料。
