# 专业更新与继续教育

## 以变化和实践判断为中心

已具备专业基础的听众通常需要知道：发生了什么变化、变化依据是什么、哪些场景适用、原有做法如何调整。先明确本次更新是证据、指南/共识、技术路线、工具、行业标准还是实践经验。

可用主线：为什么现在重看该问题 → 旧认知或路径的不足 → 新证据/新版本改变了什么 → 适用人群与情境 → 实践路径 → 争议和难点 → 可执行要点。需要多少背景由听众和更新内容决定，避免重复一整套基础课。

## 证据与版本

对“新”“最新”“推荐”“共识”“优于”等关键判断，记录适用的版本、发表/更新时间、来源和目标人群。没有当前证据时说明材料覆盖的时间范围，不用旧资料标称最新进展。

资料冲突不能只按“指南高于综述、综述高于单研究”机械裁决。比较它们回答的问题、人群/场景、方法质量、偏倚风险、版本与适用性；涉及临床时区分证据确定性和推荐强度。可以呈现尚未解决的分歧，并说明各方依据。

关键数据、实践建议与图表要有真实可定位来源。旧版和新版比较必须确认变化确实存在，不根据标题或二手摘要编出更新点。用户给的材料不足时提出具体缺口；联网条件允许且在任务范围内时核验，不能用模糊句子填充。

## 视觉与讲稿

适合的表现方式包括旧/新对照、证据要点表、适用人群分层、决策路径、流程图和实际案例。解释性短句可以保留，但保持层级与投影可读性；流程图不能把有条件的推荐绘成无条件路径。

逐页口语稿解释变化缘由及适用场景，兼顾“听懂”和“回到工作中如何判断”。没有足够依据的内容标为研究方向或讨论观点，不包装为确定实践建议。

讨论问题可围绕新路径的适用性、证据冲突、执行障碍和不同条件下的选择。真实病例和敏感业务实例需符合用户授权的使用范围；不默认上传外部平台或复制可识别数据。

## 完成依据

核对旧/新资料版本、比较条件、核心推荐限定语和引用映射；确认讲稿与页面中的方向、数量、术语一致。未完成的检索、缺失原文和有争议的实践内容显式保留，不将演示美化视为证据验证。
