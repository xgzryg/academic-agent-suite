# 图片辅助重建可编辑幻灯片

必须实际查看输入图片，不仅依靠OCR文字或文件名。如果当前宿主无法查看图片，明确缺失能力，不能虚构图片布局。读取 `../../references/engine-usage.md` 选原生或SVG精细引擎。

1. 明确目标是复现版式还是借鉴风格；默认保留用户要求的可见内容、比例和阅读顺序，分清原研究图和装饰资产。
2. 按可见元素划分：文字/数字/标签等信息层；面板、线条、箭头、表格等原生结构；照片、显微图、复杂纹理等可保留栅格。先核对真实文字和数据，不盲信OCR或生成图文字。
3. 用原生文本框/形状或SVG→DrawingML重建信息与结构。曲线、桑基流量、网络连接等具有语义的几何不能替换成不等价的普通矩形或箭头。
4. 科研照片与复杂图像等比放入，不拉伸。若仅有图表截图且缺原始数据，保留实际图像或注明近似示意；不得编造精确数据来声称已恢复原生数据图。
5. 不把整页截图做背景后称“全可编辑”。只在用户明确要求快速图像型幻灯片时走整页图片方式，并说明文字仍在图片中。
6. 渲染最终PPTX，与原图按实际内容、几何、视觉层级和编辑范围对照；用户要求高保真时核对密集标签和局部区域。修实际偏差，不机械追求像素零差。

交付时列明原生文字/形状/表格/图表、保留图片和未恢复的对象，以及为字体/显示差异作出的调整。生成工具不能代替视觉理解，图片重建不是任意输入一键无误转换。
