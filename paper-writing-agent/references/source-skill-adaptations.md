# 分支执行说明

本说明概括跨分支协作时必须保留的行为。实际任务仍需读取对应 `skills/<slug>/SKILL.md`；本文件不替代分支完整流程。

## 路由与资源

- 一个主入口协调 49 个直接功能分支和 2 个嵌套学术文风支持技能。直接分支通过 `skills/<slug>/SKILL.md` 定位，共享规则通过包内相对路径读取。
- Word 与 PDF 能力分别由 `paper-documents`、`paper-pdf` 提供；报告、检查器和其他辅助脚本在所属分支或包根 `scripts/` 中。安装时必须保留内部目录结构。
- 基础写作、语言处理与专家任务按[融合路由](integration-v1.1.md)组合，不把所有分支依次执行，也不需要用户重新选择主角色。
- 所有实质研究判断都依据当前论文、数据、图表、代码或已核验文献。工具检查产生线索；格式可解析、脚本运行成功与科学结论成立分别判断。

## 写作与语言处理

- 完整新写 Methods 或 Results 前确认大纲；局部编辑复用已确定结构，不重复启动新稿流程。缺失实验参数、数值和方法说明应列为缺项。
- 翻译按自然小块处理，保留章节、引用、术语、限定词与数字，合并时核对覆盖范围。可给可核查的误差诊断与修改理由，不索取或输出隐藏思维链。
- 润色保留科学含义、作者声音和已指定格式。Nature 风格指导用于组织论证与改善表达，不覆盖研究事实或当前期刊要求。
- 精简保留科学实质和引文；涉及实质取舍时复用用户决定或请求必要选择。明确标记的局部改写只修改指定范围，不承诺查重或 AI 检测结果。
- Highlights 按实际期刊或用户规定计数。未指定规则时可明确工作默认，不为满足条数编造结论；摘要、结论和图形摘要同样不得超过证据。

## 审稿、返修与循环

- 材料角色由用户标注与实际内容决定，不由文件到达顺序决定。文献样本可用于期刊校准，不能替代当前稿件事实。
- 多视角审稿报告实际存在的重大或次要问题，允许没有主要问题；不按意见数量机械推断录用决定。提供代码时，仅在指定范围内核查复现、数据划分、泄漏、方法与结果的一致性。
- 返修要核对当前工作稿、审稿意见、作者回答与实际已完成改动。正文、图表、逐条回复应在授权范围内同步；计划中的分析不能写成已经执行。
- 审稿—返修循环仅在用户明确开启后运行。必须由不同的真实子 agent 分别审稿与返修，不得用单一 agent 的角色模拟冒充。无委派工具时说明限制，只有用户接受后才改用顺序单 agent 工作。
- 一轮为一次返修及其再审。先有基线审稿，最多 N 轮对应最多 N 次返修和 N+1 次审稿。目标、最大轮数与是否逐轮确认独立控制；达到上限不能报告为已达到质量目标。
- 开启创新性评估时执行 PubMed 近似文献检索并逐篇比较研究问题、对象、方法与发现。检索失败或仅取得摘要都要标明；相似文章分值不是创新分数，有限检索不证明全球首次。
- 单次审稿/回复报告可同步输出 Word 与 Markdown；循环还需保留实际稿件、回应与必要轮次记录。用户显式交付格式优先。

## 投稿与校样

- Cover Letter 只填写真实确认的作者、利益冲突、预印本、同时投稿和作者同意状态。末位作者不自动视为通讯作者。缺失声明可用明确待核字段完成草稿，不能编造成肯定句。
- 编辑询问信按实际阶段选择审稿状态询问或接收后校样/制作进度询问；复用已知事实，不把系统状态解释成未知的内部进展，不编造手续完成情况，不要求返修问卷。起草不触发发送。
- 选刊可根据现有摘要作明确标注的初筛；JIF、JCR 分区、费用、时效和风险状态需要对应年份与来源。历史记录不能冒充现行核验。
- 期刊指标查询默认读取随包提供的 `skills/journal-if-lookup/data/journals_index.json`，也接受用户用 `--data-file` 指定的替代索引。内置数据按其发布年份报告，不把离线快照写成当前指标；若要回答当前状态，再核验可访问的现行来源。
- Proof 默认逐节确认；用户明确要求自动全文时连续完成。锁定转录、原句、建议和视觉证据的对应关系，区分作者错误与文本提取伪影。报告脚本不能代替实际页面检查。

## 产物与核查

Word、PDF、图表、表格和汇报材料按实际输出格式验证。复杂文档对象需要保留并针对编辑；缺少渲染能力时明确版面尚未核验。公共运行库、Office、浏览器、模型和联网权限由环境提供，安装脚本不自动安装这些依赖。

精读 HTML 在科研产物分支中使用包内预设，保留正文、图表及来源锚点，提供明暗主题、移动端目录和长页导航。主题与排版调整不删改精读内容，也不改变原有翻译流程。

个人数据、登录凭据、运行缓存和论文任务结果不写入安装包。新研究分析、外部发送、投稿、发布或系统操作分别遵循真实授权；当前任务完成后停止，不自动启动下一阶段。
