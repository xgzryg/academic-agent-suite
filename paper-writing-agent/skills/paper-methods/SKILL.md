# Methods方法写作

先读取并遵守[共享规则](../../references/shared-rules.md)。方法必须描述真实执行内容；拟议方案明确标为计划，不能把计划实验写成已完成。

## 复用输入和任务状态

- 复用当前标题摘要、完整图表/分图图注、实验记录、分析代码/输出、数据来源、期刊要求、已确认大纲和作者修订。
- PDF/Word分别调用[PDF分支](../paper-pdf/SKILL.md)与[文档分支](../paper-documents/SKILL.md)。未有完整图表但真实方法记录充分时可写，不为源推荐顺序阻断任务。
- 判断是完整新起草、按已定大纲续写，还是局部修改。只有完整新起草且大纲未确认时进入下方确认步骤；已有明确确认或局部范围不重复要求大纲批准。
- 缺失参数、未做实验和不需要报告的信息不是同一种状态，必须分别处理。

## 条件工作流

1. **对应方法与结果。** 整理每张图/表、研究目标所依赖的采样、实验、测量、预处理和统计步骤。不能凭结果倒推出未知方法。
2. **拟定新稿大纲。** 依据实际研究设计列标题与各节覆盖范围，说明主要依赖的图表或记录。新完整Methods提交大纲供用户讨论定稿，等待其明确确认后撰写正文；等待时可继续读取材料与列信息缺口。
3. **按确认大纲起草。** 如实描述对象/材料、研究时间与设计、操作、测量、数据处理和分析等项目实际需要的内容。参数缺失使用中文方括号，例如`[浓度]`、`[暴露时间]`、`[试剂货号]`、`[独立样本数]`，使缺口清楚而不冒充数值。
4. **补真实细节。** 汇总缺失项及其对应段落/图表，优先询问影响研究有效性和复现的内容；已有记录可自行查明的不再问用户。作者可用中文补充，最后按目标语言统一。
5. **形成完整方法。** 将真实补充填入相应位置，保留原数值、单位、对象、统计调整与版本信息。若用户删除关键复现项，指出影响并保持缺失状态，不能暗中补造或宣称完整。

## 产物

- 大纲阶段：章节大纲、图表/方法对应关系、关键缺失信息；此时停止依赖确认的正文起草。
- 已确认后：完整Methods草稿及具体待补项；必要时用简表列“信息—位置—所需依据”。
- 资料齐全后：统一语言、参数和术语的Methods成稿；用户要求文件时调用[文档分支](../paper-documents/SKILL.md)或[PDF分支](../paper-pdf/SKILL.md)。
- 用户还需要图注/Results时读取[结果与图注分支](../paper-results-legends/SKILL.md)，传递当前方法、事实源和已确认决定，不重新索取。

## 关键核验与停止

- 核实样本量的单位、独立实验/技术重复、剂量/时间/试剂/仪器、结局定义和统计方法与真实记录一致；不把“软件版权号”机械强加到所有软件，按实际版本/标识需求处理。
- 核方法是否覆盖文中实际报告结果，图注与Methods是否矛盾；发现实质冲突说明证据并只更新授权范围。
- 伦理号、注册号、排除规则、分析结果与执行记录均不得编造。未知项不填零，不用范文参数顶替。
- 用户尚未确认新稿大纲或未给关键真实信息时，只暂停依赖它的部分；完成其余已授权工作。未解决占位的稿件不能称为资料完整的最终方法。

## 来源与适配

写作流程参考迪娜学姐的论文写作提示词经验，并已整理为以上可独立执行的任务规则。公开包不附原课程PDF；执行无需读取原文件、页码或历史模型示例。来源署名保留，未另行赋予原材料再分发许可。
