# 论文精读与知识梳理

先读取并遵守[共享规则](../../references/shared-rules.md)。区分论文原文发现、作者解释与本分支的评论；身份、数字和图表结论须能定位到来源。

## 复用输入与阅读准备

- 复用论文、题录、语言与精读范围；先确认Research或Review，混合类型按实际结构组合流程。
- PDF读取调用[PDF分支](../paper-pdf/SKILL.md)，Word调用[文档分支](../paper-documents/SKILL.md)。需要图表内容时实际读取图表，不能只凭摘要或图注声称读完图像。
- 提取标题、作者、发表期刊与年份、DOI/URL及单位。默认用中文总结基本信息，技术词保留英文对应；用户指定语言优先。
- 记录可用正文、图、表和补充材料范围。全文缺失时明确仅作摘要/片段解读，不声称完成全文精读；已提供材料不重复索要。

## 按任务启用文献检索与引用核验

v1.1 的实际检索优先读取包内 [litorchestrator](../litorchestrator/SKILL.md) 和其所选文献工具；PubMed近似文献或创新性问题读取 [创新性评估](../paper-novelty-assessment/SKILL.md)。这些均为内置依赖，不去本机其他skill目录寻找。

1. 用户请求检索、核验引用，或前言/讨论已授权补充证据时，复用研究问句、检索框架、时间/研究类型范围及已用文献。把主题改为概念组、同义词与数据库适用检索式，保存实际查询与检索日期；不把叙述性调研自称系统综述。
2. 有联网工具且当前边界允许时，利用原始研究、数据库记录和期刊/作者官方页面查证。按宿主发现可用检索工具；需要工作区或宿主工具使用时读取[工作区与工具分支](../paper-workspace-operations/SKILL.md)。不因为旧资料提到某deep research品牌而要求该服务。
3. 先筛主题相关性，再核真实标题、作者、年份、期刊、DOI/PMID/稳定页面及文献类型；能读全文时再判断全文论点，只有摘要时明确证据范围。预印本、正式版本或撤回/更正等会改变使用判断的状态如实际出现应说明。
4. 为拟支持的句子记录对应文献和具体证据位置，检查对象、设计、方向与结论强度，避免“文献真实但不支持该句”。保留支持与冲突证据，不凭期刊名或多个模型重复推荐来确认。
5. 缺联网能力、权限或全文时继续材料内阅读，交付准确的覆盖范围、具体缺口和可复用检索式。不能伪称已联网、补造DOI/PMID或把候选文献当已核验引用；若正文原有引文需保持，先列核验问题，按授权范围处理，不擅自改号。

文献调研交付可包含检索记录、筛选说明、去重后的候选文献、研究/证据比较表、逐主张支持关系及尚未核验项。用户需要XLSX证据矩阵时主动读取[科研产物分支](../paper-research-artifacts/SKILL.md)，将已核验内容导出；不要把小规模主题调研冒称完整系统评价。

## Research分支

1. 说明主要受众、研究解决的问题、重要性、可能的实践用途；对论文尚未验证的应用注明是推断。
2. 提炼并充分解释2至4个关键概念，具体指出研究空白；数目可按论文复杂度调整。
3. 分析设计类型、研究对象、工具设备和数据分析技术；说明样本、比较、测量和时间结构等影响结论的必要信息。
4. **按编号逐图逐表阅读，覆盖每张及重要分图。** 每项给简要主题、关键证据和对应页码/图表号。无遗漏地解释图表在研究论证中的作用；不能只挑支持结论的图。
5. 汇总关键量化指标、组间比较、效应方向与不确定性。保留单位、效应尺度、CI/P等原值；无法由图精确读出的数字不估成精确数。
6. 根据结果形成3至5组关键问答，并梳理作者从问题到结论的研究逻辑。
7. 给有证据的优点、实际局限、改进与未来方向。没有某类问题就直说，不机械凑批评数量。

## Review分支

1. 用3至5句话概括综述目的、范围和主要结论。
2. 从标题、摘要及正文提取3至10个核心概念，默认格式为“中文关键词（英文原文）：释义”。
3. **依原论文全部分级标题逐节总结**，保留层级和各部分知识点、主要结论；重要图表并入相应章节，禁止因摘要化而漏掉整个章节。
4. 按时间或因果顺序梳理关键事件、方法与观点的发展脉络；原文没有明确年代时不杜撰年份。
5. 分别列出互相矛盾的观点、相似或互补观点，指出它们所依赖的证据、人群、模型或条件；区分作者的立场与自己的评议。
6. 提炼未回答的问题、可研究方向及仍需证据的地方。用户要开展选题时再读取[选题分支](../paper-topic-discovery/SKILL.md)，不能把阅读任务自行升级为完整研究计划。

## 思维导图与其他交付

- 用户需要导图时，从已完成总结提炼主题树，生成可直接使用的Markdown思维导图源码；节点忠实保留核心层级、争议和知识联系。
- 默认提供本地`.md`源码；需要HTML交互导图或PPT汇报时读取[科研产物分支](../paper-research-artifacts/SKILL.md)。宿主具备本地markmap或等价渲染能力且任务需要时再渲染，缺少渲染能力也交付源码并准确说明。不得为渲染自行把未发表全文上传第三方网站。
- 用户要论文阅读网页时，使用[本地阅读 HTML 预设](../paper-research-artifacts/references/paper-reader.md)呈现已完成精读内容，保留 Research/Review 的实际覆盖、数字、图表及来源锚点；明暗主题、移动目录和长页阅读不另启新的阅读或翻译流程。
- Research交付包含身份信息、研究问题/方法、全图表证据表、量化结果、关键问答、评论；Review交付包含层级摘要、术语表、发展脉络、观点比较和研究问题。语言和详略遵循用户任务，避免两模板无差别全贴。
- 要求Word/PDF成品时主动调用[文档分支](../paper-documents/SKILL.md)或[PDF分支](../paper-pdf/SKILL.md)。

## 关键核验与停止

- 对照论文图表编号/章节目录检查实际覆盖；图表不可读时先尝试渲染，仍不可读则标记具体缺项，完成可读部分。
- 核对关键数字、单位、样本和比较关系；论文未提供的信息保留缺失状态。
- DOI/作者信息有冲突时不擅自合并文献身份。需要外部资料核验时遵守当前网络边界，不能把记忆或检索推断写成论文原文。

## 来源与适配

写作流程参考迪娜学姐的论文写作提示词经验，并已整理为以上可独立执行的任务规则。公开包不附原课程PDF；执行无需读取原文件、页码或历史模型示例。来源署名保留，未另行赋予原材料再分发许可。
