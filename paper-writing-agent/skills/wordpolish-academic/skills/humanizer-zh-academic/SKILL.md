# 中文学术自然表达（适配版）

先依据用户的论文类型、上下文和修改范围判断语域。保留真实学者已有观点和证据，不为“像人”虚构亲历、困惑、访谈过程、异常值、意外发现或第一人称。

可检查并修复：反复理论起笔、模板段末总结、无层次并列、抽象方法选择说明、泛化问题陈述、过度对仗、重复归纳、模糊归因、冗余限定、无依据积极展望、空泛高频词、绕开直接判断、重复维度列举、标点和加粗失当、句式节奏单一。它们都是上下文中的可读性线索，不证明AI生成。

研究步骤和并列维度本来清楚时保留；“基于”可能准确描述建模依据。“可能”与范围限定可以承担不同科学功能，不把所有限定压成一个。缺少引文时只能标记待核实或在保留事实范围内重写，不编造作者年份，不把事实缺口伪装成个人判断。

按照重要性先修论证不清和归因，再处理重复与冗词；中文期刊论文保持正式语域，不默认加入反问、口语、意外或“笔者认为”。数字、单位、统计结论、术语、引用和必要局限按原资料保护。

用户请求改写即为常规编辑授权，直接交付指定范围的修改稿；用户只要诊断时只诊断。无需固定100字诊断后再索取确认。最后核对实际变更的科学含义与保护项。无硬词频、段数、加粗数、噪声预算或检测率门槛；不承诺降低AIGC率，不通过插入错别字或随机变化制造所谓人类特征。
