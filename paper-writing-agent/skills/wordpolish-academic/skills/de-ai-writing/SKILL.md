# 保真表达修补（学术适配）

普通改写先确定指定范围，只修真实冗余、空泛拔高、模板承接、含混指代或逻辑失联。不预设作者用了AI，也不要求改变既有文风。必要时读[表达问题索引](references/ai-trace-index.md)与[具体修法](references/ai-trace-detector.md)。翻译只读[翻译护栏](references/translation-guardrails.md)。

保留信息厚度、论证链、研究条件、语气强度、数据、引用和术语。默认不重排全篇；获准结构重写时才调整信息块。用户明确指定逐字保护区时原样保留。

先看结构和逻辑，再看句式与词语。删除不承载信息的“值得注意的是”可以有用，但不能机械清除它或任何连接词；真实对照、方法步骤和术语不因命中词表就改。句长、标题长、段数和词频没有统一数值配额。

审阅请求只列实际有影响的问题及最小修法，不强凑5—10项。改写请求交付正文，必要时说明无法从资料消除的事实缺口。源稿本来清楚时可直接说明无需更改。
