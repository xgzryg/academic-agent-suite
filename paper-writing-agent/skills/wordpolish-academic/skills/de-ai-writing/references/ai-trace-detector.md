# 学术表达问题与最小修法

| 真实问题 | 可采取的修改 | 必须保留的边界 |
| --- | --- | --- |
| 反复预告“下面我们将” | 直接呈现结果或逻辑过渡 | 正式章节导航有功能时保留 |
| “具有重要意义”但不说明为何 | 用已有证据写具体贡献或删冗句 | 没有依据时不新增社会/临床影响 |
| 归因含糊或缺引用 | 指向已核实来源，或标记待补 | 不把无出处事实改成作者观点来掩盖缺口 |
| 同一论证在段尾重复 | 合并/删除重复表达 | 真实结论、限定与下一段所需承接保留 |
| 多个术语指同一概念 | 复用已确认术语 | 不把真正不同的概念合并 |
| 条件句或因果句冗长 | 简化语序并明确关系 | 只保留原文能支持的因果强度和适用条件 |
| 过多限定词 | 删除语义重复的限定 | 不把不同层次的不确定性机械减到一个词 |
| 段落等长但重复 | 围绕信息功能调整顺序/篇幅 | 只在获准重组时移动，保留全部关键证据 |
| 宣传式形容词 | 改成具体效应、比较与适用范围 | 不编造数量、场景、人物或亲历 |
| 标点/格式不一致 | 按用户/期刊约定统一 | 保留公式、统计符号、代码、引用与保护区 |

清楚的表达可以保持原样。不要把“少模板”写成另一套统一模板，不以降低检测率验证质量。只做一次有目的的编辑和变更核查；修复发现的偏差后结束，不持续迭代词表。
