# 保结构翻译与学术保真

以用户指定目标语言为准。中译英论文可调用主包论文翻译分支；其他情况下不擅自把中文编辑变成英译。

保留段落、标题、列表、表格单元的对应关系，以及信息点、研究条件、否定、逻辑关系、证据强度、引用和数据。句内可调整语序、合并/拆分句子以适配目标语言。除非用户授权重组，不合并段落或改变论证顺序。

代码、命令、URL、路径、ID、版本号、公式、占位符和指定术语原样保护。专名使用项目或领域已确认译法；不凭空造译名。保留Markdown/LaTeX结构语法，普通可译表头和正文按目标语言处理。

忠实翻译后检查涉及的术语、数字、条件和语气强度，并修复确有必要的翻译腔。不同自然语言不必机械逐字对应。无依据补充、不必要总结和未请求评价不能加入正文。源文实质歧义无法安全消除时说明该点，不用流畅语言掩盖。

默认输出目标文本；用户要对照或说明时提供。用户允许自由改写只放宽结构，不取消科学保真与事实边界。
