# 论文创新性与近似文献评估

本分支评估证据支持的研究增量；不保证新颖、首次、达到某个期刊水平或被接收。先读取 [PubMed](../pubmed-database/SKILL.md) 及其执行器说明；复杂多源任务再读 [文献调度](../litorchestrator/SKILL.md)。

## 1. 定义需要核查的主张

从稿件明确提出的贡献中提取可检验条目：问题/假设、研究对象与场景、数据或队列、方法与对照、验证方式、关键发现和适用范围。为每条主张保留稿件段落或图表位置。作者没有宣称“首次”时不要自行扩成世界首次检验；作者主张过宽则比较证据后提出缩窄建议。

沿用已确认的研究范围、联网许可、日期范围、预算和种子论文。无特殊限制时，快速查新可声明采用3–5个互补查询、每个最多20条、选取3–8篇最接近研究详细比较；这只是执行预算，不是完整性或质量保证。不要求强凑篇数；实际相近研究更少或证据不足则如实报告。审稿循环共享已有检索结果，只有新增主张、重要证据缺口或过时范围才补检索。

## 2. 设计宽窄查询和种子近邻

至少覆盖核心概念的同义词、旧术语与MeSH（适用时）：一个宽查询查问题和对象，一个较窄查询查方法或关键发现。不能所有关键词一律AND造成虚假空白；不要默认排除早期研究、非英文、低IF或非免费全文。近期研究可以另设时间窗口，但保留先行研究检索。

种子必须来自用户给定或真实返回记录并已核对身份；通过 ELink `neighbor_score` 发现近似论文，保留每个种子的归属，删除结果中的种子自身后按需读取。检索排序和相似分仅为候选发现，不能当新颖性分数。

只有通用公开术语或已公开标题进入外部请求。不发送未发表稿件全文、机密数据、私人同行评审意见或整段独创方法细节，除非用户明确授权相应披露。可用已公开研究术语完成普通查新，不因此索取不必要确认。

PubMed只覆盖其索引范围。涉及计算机、工程、预印本等明显覆盖缺口时，按已授权范围用 [academic-literature-search](../academic-literature-search/SKILL.md) 补官方arXiv、Crossref或其他可用源，明确已查/未查来源；不把PubMed零结果扩展为全领域无先例。

## 3. 实际读取与逐篇比较

保存检索日期、全部执行过的检索式、数据库、筛选范围、总命中数、实际取回数量、截断状态、筛选理由、PMID/DOI、真实标题与摘要。网络错误、语法错误、缺失摘要、相关性不符、未取得全文分开记录。

阅读最相近研究的完整摘要；关键方法或发现只在正文可判断时按授权获取全文并用 [nature-reader](../nature-reader/SKILL.md) 定位相关段落、图表和补充材料。查新不要求输出整篇双语翻译；只需支撑对比时按审稿范围读取。未读到的方法、验证或数据不能从题目猜测。

按 [比较模板](references/novelty-comparison.md) 逐项写：相同内容、已知先例、本稿新增内容、增量的证据位置、意义与仍未确认之处。区分：重复既有结论、在新数据/人群复现、方法或资源扩展、明确机制或发现增量、尚无法判断。新数据、新地区、换模型或更大样本可能有价值，但不能自动等同突破。

## 4. 返回审稿与返修

给每条创新性意见关联真实文献和稿件位置，说明对核心贡献的影响；不设固定负面发现数量。如果已有贡献表述正确，明确判定可保留。建议可以是补引、明确先例、缩窄首次措辞、重排贡献、补充真实对照或如实列为未来工作；不得伪造实验或夸大措辞以“提高创新性”。

审稿子agent独立判断证据，返修子agent修改实际工作稿并保留来源。返修若改变核心主张，由下一次审稿复核增量是否仍成立；只增加引用未必解决重复性。循环目标必须是具体的证据/表达问题处理完成，不能用越来越高的主观创新分或“保证接收”。

最终结论用“在本次已说明的检索与阅读范围内……”限定证据范围，并具体陈述增量。有限检索不能证明不存在任何先例；“首次”未被充分证实则标记未证实并建议精确表述。检索失败时交付策略和已完成部分，绝不伪造已完成查新。
