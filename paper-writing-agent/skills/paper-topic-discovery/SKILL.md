# 选题与文献主题分析

先读取并遵守[共享规则](../../references/shared-rules.md)。本分支针对真实语料选题；不得把示例论文、模型意见或关键词缺失当作已验证的研究空白。

## 复用输入并确定范围

- 复用已给的研究领域、主题偏好、文献列表、数据字典、可用波次和资源限制。优先利用含标题、摘要、年份的CSV；其他可靠格式同样可用。
- 读取PDF先调用[PDF分支](../paper-pdf/SKILL.md)；Word调用[文档分支](../paper-documents/SKILL.md)。文献列表缺摘要时注明分析依据较窄，不捏造内容。
- 区分“分析已给语料”与“补充外部检索”。仅有本地语料任务时不擅自扩为全网检索。当前会话已允许的检索按宿主能力和共享规则完成，不增加来源不存在的独立审批。
- 数据可行性至少核对研究对象、字段定义、测量波次、暴露先后、结局来源、样本范围及设计限制。缺失的关键数据字典先列为待查证，不能直接承诺方案可做。

## 执行流程

1. **先分析语料。** 识别记录数、年份跨度、字段和可读性；分离标题、摘要、作者关键词。仅做有助主题识别的去重和词形/同义词整理，保留原记录与词义对应。
2. **制作主题地图。** 采用关键词计数/共现或TF-IDF分析形成主要主题与交叉主题。工具和语料适合时再做聚类；不强制为小样本运行聚类。说明输入字段、关键词规则、主题划分及对应文献，以证据识别拥挤与稀疏区域。
3. **处理失败。** 解析或聚类失败时定位缺字段、空文本、分词或算法问题，修正后重试；条件不适合时改用可解释的关键词计数/人工主题归类并说明。不能无界重试或声称聚类成功。
4. **生成候选。** 默认提供6至10个选题，数量服从任务。以可行性及用户偏好排序，解释主要取舍，不用无依据的精确评分代替判断。每题填写下方Topic card。
5. **选择后细化。** 等待用户明确感兴趣的题目再深化；已有题目选择直接沿用。读取[研究设计](../paper-study-design/SKILL.md)，细化研究问句、设计、统计、图表和注意事项。不得自行扩增候选或启动数据分析。

## Topic card与实际交付

每张卡必须包含：

- **题目与研究问句：** 对象、暴露/干预、结局和比较关系，区分探索性问题与验证性假设。
- **新意依据：** 语料中已有工作、稀疏交叉点及支持记录。关键词“同现为零”只说明当前语料未找到，不能表述为全球首次。
- **可行性：** 已验证变量与时间信息、设计需求、资源和关键缺口；拟议代理指标必须说明构念依据，不能冒充原数据库字段。
- **候选方法：** 方法与问句、数据结构的对应理由及识别限制。不得直接套用示例的轨迹、潜类别、Cox或中介模型。
- **预期产物与主要限制：** 可回答的问题、图表或实验材料、无法回答的部分及下一步需要的信息。

交付主题分析摘要/主题表、可追溯的Topic cards、候选排序理由，以及仅针对已选题目的细化方案。用户要求XLSX主题/证据矩阵或主题可视化时读取[科研产物分支](../paper-research-artifacts/SKILL.md)；需要Word时调用[文档分支](../paper-documents/SKILL.md)完成文件，不只给创建建议。

## 关键核验与停止

- 检查每题是否引用已分析文献并对应真实可用数据；没有查阅用户语料不能交付为“基于文献的选题”。
- 没有关键变量或时间设计依据时只暂停对应可行性判断，其他主题分析继续完成。
- 已有授权不重复索取；未得到选题偏好时不自行开始后续完整研究方案。
- 不承诺发表、创新评分或统计显著性，不把计划写成已执行。
