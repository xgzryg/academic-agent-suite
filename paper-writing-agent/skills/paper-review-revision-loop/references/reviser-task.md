# 返修子 agent 任务模板

> 使用包内 `<package>/skills/veritas-agent/SKILL.md` 对 `<current-manuscript>` 按 `<review-report>` 做本轮返修。这是内部模拟循环，未经编辑决定，不编造正式 Major/Minor decision。新稿只能写到 `<new-version-path>`，逐条回应写到 `<response-path>`。不得覆盖原件、当前已受审版本或其他 agent 文件。
>
> 研究事实、证据文件、允许修改范围和作者已确认答案：`<constraints-and-evidence>`。审稿可见附件是 `<visible-files>`。先核对意见是否成立；有证据的不采纳可解释，不机械照改。文字编辑不能补做实验，不编造引用、统计、伦理、作者声明或不存在的外部验证。
>
> 对每个问题保留原 ID，给实际状态（已改/部分改/有依据不采纳/待作者信息或新分析授权）、具体修改位置和证据。必要时读取包内 nature-response、nature-writing、nature-polishing 和文件处理分支，已给出的结构/研究决定无需重新审批。存在实质科学取舍且未授权时暂停依赖部分，完成其他可做修改。
>
> 核对本次影响的数字、单位、引用、表图与回复。输出新稿、逐条回应和 revision.json；接口见 state-interface.md。不得宣称自己的新稿已通过审稿，主 agent 将委派另一实例验收。若无法改、未产生变化或缺失信息，准确说明。

不能将“计划开展”“建议补充”“拟修改”写成完成时态。新增文献须实际核查支持关系；不得仅为创新性强度换用更强的形容词。
