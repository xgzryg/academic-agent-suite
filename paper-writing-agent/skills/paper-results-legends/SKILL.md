# 图注与Results

先读取并遵守[共享规则](../../references/shared-rules.md)。图注、Results、实际数据和Methods需要一致；图像不能提供的精确数字或实验条件不得猜测。

## 复用输入与选择子流程

- 复用标题摘要、每图主题、实际图像/表格、分图标记、定稿图注、真实统计结果和方法记录。按用户请求选择“图注”“Results”或串联两者，局部改图注不自动改全文。
- PDF和Word输入分别使用[PDF分支](../paper-pdf/SKILL.md)、[文档分支](../paper-documents/SKILL.md)。需要核对方法时读取[Methods分支](../paper-methods/SKILL.md)，复用已确认信息。
- 原材料建议一次一图以便逐步补充；批量图表已可读时直接处理，不要求用户重新逐张上传。
- 识别当前稿与人工修改，不只按编号或最新时间选图。标题/摘要与数据冲突时以真实依据核查，不为迁就叙事改数据方向。

## 图注流程

1. 逐图及分图读取内容，建立“图号—主题—分图—比较/测量—来源”对应。每张图及必要分图都覆盖。
2. 起草图注：清楚说明展示内容、对象/条件、分图、单位、样本/重复、统计表示和符号含义等实际需要信息。保留目标期刊风格，图注应尽可能独立可理解。
3. 未提供的量、时间、试剂、仪器或软件标识等先查现有材料；仍未知则列明确待补项，等待作者提供真实内容后完成该部分，不用常见参数填空。
4. 吸收补充和作者修订，形成完整图注；保留真实阴性、相反或不确定结果，不把解读性机制写成图像直接证明的事实。

## Results流程

1. 基于实际图/表、定稿图注与可靠结果数据组织研究主线。既有图注对话/文件中的信息直接复用。
2. 新完整Results且尚无确认大纲时，列小标题、各标题包括的图表和分图及逻辑关系，提交作者讨论定稿。**等待明确大纲确认后撰写正文。** 已定大纲、已授权局部修订不再走该确认。
3. 依确认框架完成各heading正文，说明比较、观察和主要量化结果，并引用对应图/分图。重点由实际结果和研究问题决定，不靠漏报不支持结论的结果突出主线。
4. 区分Results中的观察与Discussion中的解释；需要机制讨论时只记录可交接要点，不把未验证推断写成结果。
5. 完整重组Results并核全图表引用、数值、分组和方向。需要讨论写作时读取[Discussion分支](../paper-discussion/SKILL.md)，传递已定结果和引文边界。

## 实际产物

图注任务交付按图号排列的完整图注及具体缺口；Results大纲阶段交付章节与图/分图映射；确认后交付完整Results及必要未解决信息。文件交付调用[文档分支](../paper-documents/SKILL.md)或[PDF分支](../paper-pdf/SKILL.md)。

## 关键核验与停止

- 对照图/表和分图编号检查覆盖与引用，核图题、图例符号、单位、样本、效应尺度/CI/P和方向，不从图估计精确值替代数据表。
- 图像不可辨识先尝试合适渲染；仍不可读则标记具体分图，完成可读部分，不宣称全图解读。
- 新Results未确认大纲时停止正文；关键图注参数缺失时停止依赖的句子，保留占位并完成其他图。
- 不重新分析数据、不创建新模型版本、不为了文章重点改变统计或选择性呈现，除非任务明确授权相应工作。
