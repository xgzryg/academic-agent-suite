# 科研工作区与宿主操作

遵守[共享规则](../../references/shared-rules.md)。本分支内置的是工作方法；不会通过复制文件获得账户、浏览器、连接器、Sites、远程或定时服务。每次先发现实际工具，并遵循其当前规则。

## 项目接手、版本与恢复

只读扫描项目说明、目录索引和候选主稿，区分原始数据、处理结果、图表、文献、工作稿及人工固定稿。按内容和依赖识别当前版本；必要时只问无法确定的真实歧义。目录建议不是移动/重命名授权。

同论文的新信息更新当前目标，错误输入应停止依赖工作并切换正确源。长任务只保存自然阶段：输入、关键决定、当前产物、完成块、待补和下一步；继续前核当前进程与结果，复用有效阶段。

文本/代码项目有需要时用现有 Git diff 核改动范围、数字/限定词和 TODO；Office 项目可用修订/文档比较。Worktree 仅在真实 Git 项目和宿主支持时采用，不为并行复制受限大数据。提交、合并、移交按实际授权，不从版本管理建议推断允许提交。

## 科研代码报错与可复现修复

用户请求修复 R/Python/MATLAB 等分析脚本时，先在当前真实输入和既有环境中复现错误，记录实际命令、相关版本、完整错误以及最后可用输出。核实文件路径、字段/数据类型、依赖和当前代码，依据证据定位根因；不要一开始重写整个项目或更换分析方法。

在授权范围内做最小代码修复，保留原始数据、已确认分析目标、纳排和统计口径；随机流程记录种子与必要版本。实际重跑受影响阶段并比较关键结果，说明程序恢复、方法变化与结论变化各是什么。流程跑通不等于研究结论已复现；发现数值变化要解释根因并同步授权范围内图表/正文。需要改变科学方法而尚未获得决定时暂停该部分；条件未变不循环重试。

## 并行与持续任务

只将能独立执行的文献子集、机制/方法问题或已明确标准的审查拆分。子任务接收最小必要材料、授权和事实源；不同编辑者不同时写同一文稿。主执行者比较证据、合并术语并处理冲突。是否允许委派以及可用模型遵循当前宿主和用户决定。

用户明确要求 Goal、新任务、置顶/归档/命名、分享或远程管理时，发现对应真实工具后执行；不从“长期研究”自动创建 Goal 或新任务。工具不可用则提供任务简报和手工操作说明，不虚称已设置。

## 公开检索、登录页面与 GUI

公开期刊/学术资料检索优先官方出版页面、原始研究和正规数据库。记录来源、版本与核查日期；不要把搜索摘要等同全文。用户禁止联网时只用本地资料；未发表全文和患者数据不能夹入搜索词或未经授权外传。

用户要求操作现有登录页面时，核真实页面对象与允许动作；内置浏览器不假定共享日常 Chrome/Edge 登录状态。用户指定不刷新/不新开标签时保持。验证码、二次认证和授权弹窗交回用户，不绕过。不点击 Submit、付款、接受协议或更改作者资料，除非对应操作明确获准且满足必要确认。

API/文件方法足够时优先使用；仅必须界面操作且工具可用时采用 GUI。Mac/Windows 权限、前台占用和文件路径按当前实际环境处理；不照抄指南旧快捷键，不要求修改执行策略或开管理员窗口。只读诊断不接受全部修订、不保存覆盖原件。截图查看受当前工具使用条件约束。

## Sites、插件、MCP、Hooks 与自动化

- 网站：先判断用户实际需要，再本地/私有预览、核关键交互和数据访问；准备好可审阅结果后满足授权再部署，部署后访问真实 URL 核验。不以建网页授权外传患者数据。科研/教学演示不能凭页面或模型输出宣称已具备临床诊断用途。
- 插件/连接器：先发现已装能力，说明缺少的具体工具；安装/授权遵循宿主可用机制和用户请求，不模拟安装成功。
- MCP：在实际可用接口和权限内读写，连接能力不能代表写权限。
- Hooks：仅用户要求或项目已有且本次相关时维护确定性检查；不为普通写作添加新的全局门禁、hash 系统或后台脚本。
- 定时/监测：仅明确请求后用宿主自动化工具配置，先验证一次任务；保存数据源、时间窗、无变化保持安静、意义变化通知、成功/失败和停止条件。本地任务依赖设备/应用在线；不能用一个 skill 宣称已创建定时服务。
- 记忆/远程：事实以当前项目文件为准，只有明确请求才写持久记忆或设置远程。远程不绕过数据权限，个人偏好不替代当前期刊政策。

完成时给实际产物、操作结果和证据；未执行的外部操作明确保持未执行。功能不可用时交付能继续执行的具体简报，不无限等待、不承诺聊天结束后自动醒来。

本分支独立说明实际任务中可用的工作区操作；不需要原构建资料。平台能力与快捷键需要当前核查。
