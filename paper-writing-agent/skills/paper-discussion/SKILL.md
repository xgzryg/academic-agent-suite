# Discussion讨论

先读取并遵守[共享规则](../../references/shared-rules.md)。本研究结果、外部文献和风格范文分别处理；最终正文只能使用已授权的本研究结果与文献综述证据，不擅自新增科学内容。

## 输入复用与工作范围

- 复用当前标题摘要、Introduction、Results、图表、已定讨论框架、文献综述稿和作者补充。已有框架或局部修订直接进入对应阶段，不重走整个流程。
- PDF/Word用[PDF分支](../paper-pdf/SKILL.md)和[文档分支](../paper-documents/SKILL.md)；需要检索、核验或精读外部论据时主动读取[文献检索与精读分支](../paper-literature-reading/SKILL.md)执行。
- 明确目标语言、字数单位、期刊结构和允许增补证据范围。源中的1500字讨论、2000字调研、2至3倍篇幅皆为示例，不固定。
- 范文只学习结构、段落与文风，不能借其结果、样本、数字或引用填进本研究。

## 阶段一：讨论框架

1. 尚无确定框架时，围绕主要结果提供三种有差异的组织方案及理由，说明如何与既有研究对话；局部任务不强制生成三套。
2. 每个主题列核心结果、要比较的问题、所需证据/检索词和篇幅预算。合理分配重点，避免把讨论写成宽泛背景综述。
3. 规划发现总结、与文献/理论/方法/样本的比较、可支持的解释、真实局限、未来方向和结尾。可有小标题或结论段，按用户与期刊安排。
4. 不同主线需用户决定时保留框架选择；已指定框架或授权代选时直接沿用，不为每段另造批准。

## 阶段二：批判性文献调研

1. 按采用的框架逐主题检索/审读，检索提纲可去掉篇幅限制。优先相关近期高质量原始证据，同时纳入必要经典工作。
2. 对每条结论明确标记来自“本研究”还是“外部文献”；记录研究对象、设计/模型和条件，解释何以可比或不可比。
3. 比较一致、相反与互补发现，分析方法、样本或生物学条件等有依据的可能原因；推测保持推测语气，不冒充验证结果。
4. 现有综述证据不足时给具体缺口；允许补检索时依当前网络边界核查。没有联网时不伪造引用或当前期刊要求，继续整理现有证据。不添加来源没有的独立联网审批。
5. 多份综述或多模型材料只能用于定位证据，不能以相互复述作为证实。补入的证据放在对应主题，保持可追溯引用。

## 阶段三：Discussion全文

1. 严格按采用框架，仅写Discussion范围。每段围绕一个分析重点，以清晰主题句、研究结果、文献比较和适当解释推进。
2. 讨论研究问题得到何种回答、假设获得多少支持，以及对现有知识的具体贡献；不要只是重复Results数字。
3. 保留真实限制，并从限制导出可执行的未来研究方向；不能以讨好审稿人为由堆叠假设性弱点，也不应删除决定证据上限的限定。
4. **文内引文原样保留**，包括作者年份或数字编号；不得把引用转挂到其未支持的结论。正文不超出已提供/已核查并获授权纳入的综述与本研究结果。需要额外内容时先给具体补证据需求。
5. 使用客观、精确、正式且易懂的语言，长短句自然结合，段内段际衔接连贯。避免无依据的“首次”、striking等夸大；不把关联写为因果，尊重地批评其他研究。
6. 结尾回扣前言问题和研究目的，重申数据真正支持的结论与意义；应用/转化推断保留条件。

## 实际产物、核验与停止

- 依用户阶段交付框架与检索词、分主题比较证据材料、或完整Discussion；必要时附仅影响结论的证据缺口和取舍说明，不公开隐藏思维链。
- 核自有/外部结论是否混淆，引用是否支持对应句，结论是否受设计约束，局限和未来方向是否有实际依据，首尾与Introduction一致。
- 重要结论缺证据时只暂停对应论证，完成可支持段落；不以空泛长段填补证据缺口。
- Word/PDF交付调用[文档分支](../paper-documents/SKILL.md)或[PDF分支](../paper-pdf/SKILL.md)。需要同步前言时读取[Introduction分支](../paper-introduction/SKILL.md)，仅改授权范围。
