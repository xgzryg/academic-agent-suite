# 标题、摘要与结论

先读取并遵守[共享规则](../../references/shared-rules.md)。按任务选择一个或多个子流程，不因用户只要标题就扩写摘要和结论。

## 复用输入与事实范围

- 标题主要使用摘要、研究主题和目标期刊；摘要使用实际标题、Introduction、Results及必要Methods；结论使用标题、摘要与结果。已提供输入和作者决定直接复用。
- PDF/Word使用[PDF分支](../paper-pdf/SKILL.md)和[文档分支](../paper-documents/SKILL.md)。复杂结果需核对时读取[结果与图注分支](../paper-results-legends/SKILL.md)。
- 复用目标语言、字数或字符限、结构式/非结构式摘要、结论段落要求与术语表。期刊当前规则需要时按共享规则核查，不能把原资料中的期刊例子当当前规范。
- 指定期刊范文可用于语气、结构和篇幅学习；不移植其数据、科学事实、引文或作者身份。默认数目和结构服从任务。

## 标题子流程

1. 从真实摘要提取对象、研究关系/问题、最主要发现和必要设计信息。
2. 默认给3个实质可选标题，分别说明表达侧重点；用户要单一成稿或固定数量时按要求输出。
3. 保持简洁、信息充分、术语准确，加入直接相关关键词以便检索；吸引力不能靠夸大、“首次”或未支持因果。
4. 核标题覆盖的是实际研究对象与结论，避免标题比摘要/数据更强；英文大小写和缩写按期刊或用户约定。

## 摘要子流程

1. 提取背景中的具体问题/争议、研究目的、必要设计与对象、关键结果、结论和意义。Methods不足时标出关键缺口，不凭Results猜测实施细节。
2. 按期刊结构组织摘要；不指定时采用合理的背景—目的/方法—结果—结论逻辑并说明默认。学习可选范文的结构，不抄范文内容。
3. 按重要性呈现核心结果，保留会改变主结论的阴性、相反或不确定发现。字数有限时综合呈现，不要求照抄Results所有数值，也不能只保留显著结果。
4. 准确保留数值、小数、单位、效应方向和尺度，必要CI/P与比较对象一致；不把HR、RR和OR互换，不改关联为因果。
5. 术语首现通常用“全称（缩写）”，之后一致；摘要具有独立阅读边界，目标期刊明确要求优先。正式、简洁、客观，避免口语、重复与无意义连接词。
6. 用完整文本对照输入，确认研究主题、对象、方法和关键发现一致；按用户要求给字数或字符数，无法达限又不损害实质信息时说明具体取舍待定。

## Conclusion子流程

1. 从研究问题和真实Results提炼总体结论，明确什么得到支持、什么仍有限制；不引入正文之外的新结果或新分析。
2. 按原稿和期刊语气撰写，通常一段；目标期刊要求多段或独立结构时遵从，不能把源示例的一段式固化。
3. 源提示推荐英文，与原稿风格一致；用户指定语言优先。保持中性客观，实际应用或未来意义须受证据条件限制。
4. 不把观察性关联升级为临床推荐或因果结论，不用空泛“需要更多研究”代替具体结论，也不为强化意义编造发现。

## 实际产物、核验与停止

- 交付用户请求的标题候选/定稿、完整摘要、或Conclusion。附必要的篇幅信息和会影响最终稿的真实缺口；不加未请求的论文其他部分。
- 核数字、符号、术语、研究对象和结论方向在标题—摘要—结果—结论间一致；已有不一致时指出依据并在授权范围内修订。
- 缺关键信息时只暂停依赖它的表达；不能用风格范文或记忆填数据。主研究目标不明确且会改变主题时先澄清，继续可完成的输入整理。
- 文件交付使用[文档分支](../paper-documents/SKILL.md)或[PDF分支](../paper-pdf/SKILL.md)。
