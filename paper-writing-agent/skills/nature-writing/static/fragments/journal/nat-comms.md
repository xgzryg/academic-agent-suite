# Journal: Nature Communications (drafting)

Read `../../../../nature-shared/journal-formats/nat-comms.md` for the dated
Article requirements and live-check scope. Do not duplicate numeric rules here.

Write for the journal's actual scientific community and adjacent researchers.
Name the real contribution and preserve its limits. Build an accessible abstract
around context, the main result and bounded implications. Use the current
Article abstract limit rather than the old 150-word local default.

Count the main text using the shared exclusions; Methods is counted separately.
Retain necessary evidence and reproducibility. For a length edit, show the
relevant before/after counts; do not delete substantive results without the
authorization to make that change. Minor language editing can proceed while
flagging a remaining submission requirement.

Apply display, reference and structure checks to the requested stage and article
type. Preserve a permitted anonymized, embargoed or controlled-access workflow;
do not equate initial submission with final production. A cover letter may
address finding, novelty and fit in a concise paragraph without a fixed sentence
quota. Reuse supplied author facts and prior decisions.
