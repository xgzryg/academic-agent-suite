# 论文精简与字数控制

先读取 [共享规则](../../references/shared-rules.md)。本分支进行有边界的删冗余与压缩表达；翻译、语言润色或重复表达改写不能暗中扩大为内容删减。精简范围包含 Methods 或补充方法时，还要读取[方法直接陈述与跨章节去重规则](../../references/methods-directness-and-redundancy.md)，确认一个完整、正确放置的事实陈述仍然保留后，才删除跨章节重复解释。

## 判别与依赖

- **全文预算模式：** 用户有总字数目标但不知删哪里，通读当前全文后给 section 级预算与具体建议。
- **指定章节模式：** 用户指定一个 section 及目标，读取必要全文上下文后只精简该 section。
- **执行已选方案：** 用户已经选定删减建议或明确授权语言压缩，直接执行，不重走选择。
- PDF/Word按需读取 [PDF](../paper-pdf/SKILL.md) 或 [文档](../paper-documents/SKILL.md)。所有调用只走包内路径。
- 字数核算可用本分支 [计数脚本](scripts/count_words.py)，仅依赖Python标准库；未发现运行时时不自动安装，改用宿主已有可靠计数能力，并如实说明口径及是否实际运行。

## 明确目标和保留项

从已有材料取得当前稿、范围、期刊要求、目标字数、是否包含标题/摘要/图注/表格/参考文献、允许调整的结构和作者固定项。已提供信息不重问。

先确定计数口径：
- 英文通常用词数；本脚本按空白分隔，并排除纯符号项，连字符词和缩写默认算一项。不得把这一口径冒充所有期刊/Word的算法。
- 中文可按非空白字符数报告；明确是否含标点。脚本的 `nonspace-characters` 包括标点，不能称为“汉字数”。
- 用户已有期刊/Word统计口径时优先采用；混合语言不把英文words与中文字符直接比较。
- 标题、摘要、参考文献等纳入与否按当前实际规则。在单独的纯文本副本中选取计数范围，避免把报告说明或Markdown标题算进论文。

建立必须保留的核心发现、数值及单位、方向、论证链、引用、定义和可复现方法细节清单；只列与当前稿有关内容，不扩成通用审计。

## 先评估，再按实际决策执行

1. 完整读取目标全文或已指定 section 及必要上下文，理解每段在论证中的作用。
2. 用实际计数给出当前词数；估计可删减额度时标明“估计”，不要把模型估数当最终计数。
3. 对未知删减范围的任务，给简洁方案表：

| section | 当前计数 | 建议目标/可删范围 | 具体操作 | 需要作者取舍的实质内容 |
|---|---:|---:|---|---|

4. 建议必须指向实际段落，如合并重复背景、删去重复解释、缩短已定义术语的重复展开、压缩不必要连接语。避免只说“更简洁”。
5. 合并段落、删除独立结果、删限制、删人群/方法信息或将正文移到附录属于实质取舍。**未有明确授权时提出具体建议并等待作者决定这些取舍**；在等待期间可完成无须该决定的语言压缩。
6. 不要求作者逐条批准明显可逆的表达压缩，也不重问已经采纳的方案。源文逐轮粘贴只是工具使用方式，代理应自己保留材料和阶段。

## 执行规则

- 按文章顺序逐section处理，允许跳过无须精简的部分；局部任务不自动压缩整稿。
- 只改需要精简的内容，准确且无冗余的原句尽量保留。
- 保持原意、学术语气、逻辑衔接、主要论点、核心数据与证据强度；不能把“不显著”删成有效，不能删限定后夸大结论。
- 保留与保留论断对应的参考文献。段落合并时准确保留引用归属；不得通过删引用或换编号满足字数。整段与引用需随明确取舍删除时一并检查依赖。
- Methods保持理解和复现所需的人群、数据、测量、主要分析与关键参数。将细节移到补充材料必须真的有对应可交付补充文本，且在授权范围和期刊规则内；不能只从正文删去。
- 对同义信息作准确合并，不为省字引入罕见词或难懂长句。
- 目标过紧而必需信息不能完整保留时，给出目前可安全达到的计数及具体取舍项，等待实质决定；不暗中删关键事实。
- 逐节完成后检查与前后节术语、图表和论证的一致性，再组装完整目标范围。

## 实际计数用法

先将选定计数范围保存为任务目录内UTF-8纯文本，再用宿主发现的Python解释器调用已解析为绝对位置的本脚本：

```text
python <此分支的实际目录>/scripts/count_words.py <原文.txt> <精简稿.txt> --mode english-words
```

路径由当前skill文件位置解析，不假设工作目录，不写构建机器路径。脚本输出每个文件的计数、减少量和减少比例，不修改输入。对于中文含标点的非空白字符数，将模式改为 `nonspace-characters`。期刊另有规则时用符合其口径的计数器，并说明差异。

## 输出与完成标准

- 规划阶段：当前计数和口径、section级建议、具体实质取舍。不要在作者尚未选择时假称已实施。
- 执行阶段：目标section或范围的完整精简文本；实际前后计数、减少量与目标是否达成；若改变引用/段落等结构，简短解释实际发生的变化。
- 默认无需重复展示每处同义词替换；只有追踪修订/对照要求时生成相应文档。
- 完成前核对核心数据、论点、方法、引用、限定词和段落衔接是否保留；计数范围正确，目标达成或具体限制已清楚记录。
- 不将语言压缩升级为重新分析、扩写讨论或改变研究结论。
