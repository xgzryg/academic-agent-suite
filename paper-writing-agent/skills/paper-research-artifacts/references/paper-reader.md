# 本地论文阅读 HTML

用户要论文阅读网页、精读可视化或全文阅读的浏览器预览时，使用 [HTML 模板](../assets/paper-reader.html) 和 [渲染脚本](../scripts/render_paper_reader.py)。Python 3.10+ 标准库即可，页面自带样式与交互，无需 CDN、服务器、Node 或网络连接来阅读基本内容。

## 内容交接

先完成当前任务要求的论文阅读，再渲染。沿用原有范围：Research 精读保留逐图逐表、量化结果和解释，Review 保留章节层级、观点与证据；全文中英对照预览保留原文、既有译文、每个来源块及图表公式，不改成摘要，也不重新运行翻译。`paper.md`、`source_map.json` 等原主产物仍按原分支交付。

渲染器仅接收已准备好的 HTML 片段；它不检索、不总结、不翻译、不推算数字，也不判断覆盖是否完整。将已核对的正文转为 HTML 时保留原有 `S001`、`F001`、`E001` 等来源 ID 和链接。章节使用另外的唯一 ID，例如 `sec-methods`，不要与正文锚点重名。页面内部 `pwa-` 前缀由模板使用。

## 输入 JSON

将 JSON 和需要嵌入的图放在用户任务目录中。必需字段为 `title`、`coverage`、非空 `sections`；每节必需 `id`、`title`、`html`。其余字段可省略。`coverage` 用真实的覆盖说明，例如“已读正文第 1–8 页及图 1–4；未提供补充材料”，不能让模板替判断。

```json
{
  "title": "用户论文真实题名",
  "subtitle": "可选的阅读说明",
  "label": "RESEARCH / 论文精读",
  "metadata": ["作者与期刊信息", "DOI 或 PMID（已核对）"],
  "coverage": "填写实际已读正文、图表及缺失范围",
  "lang": "zh-CN",
  "sections": [
    {
      "id": "sec-background",
      "title": "研究问题",
      "html": "<div id=\"S001\"><p class=\"source\">来源：第 1 页 S001</p><p>从已完成精读结果中保留的正文。</p></div>"
    }
  ]
}
```

`metadata` 为纯文本字符串列表；引用链接放入章节 HTML 中。文字字段自动转义。`html` 为本次 agent 从已核对材料准备的片段，不直接粘贴未经处理的整个出版社网页；不包含脚本、外部样式、嵌入页面或事件处理器。

可复用的片段类：

- `source`：来源说明；可用 `<a href="paper.pdf#page=2">第 2 页</a>` 链回任务目录中的原 PDF，或链接已核对的正式网页。
- `bilingual` 下的 `original` 与 `translation`：桌面两列、窄屏上下排列。仅装入原有中英对照内容，不改变翻译流程。
- `note`：作者说明、证据边界或缺失材料说明，内容由阅读结果提供。
- `<figure id="F001"><img src="assets/figure-1.png" alt="忠实说明图中内容"><figcaption>原图注与现有译文；第 3 页。</figcaption></figure>`：本地图片自动嵌入。使用相对输入 JSON 的文件路径或已有 `data:image`，支持 PNG/JPEG/SVG/GIF/WebP；不要把模型画出的假实验图放入。
- 普通 `<table>` 自动获得可键盘滚动的横向容器；使用真实 `<thead>`、`<th>` 和 `<caption>`。宽表可按需要给表设置最小宽度，避免为了窄屏删列。

段落内引用 `href="#S001"` 必须能在页面中找到相应 ID。重复 ID、无目标内部链接、缺失本地图、远程图片等会报出具体错误，先修正内容或资源再交付；不静默删图。链接到原 PDF 等本地资料时会按输出位置重算相对路径；原资料仍需随任务目录保留，**不被嵌入 HTML**。外部文献链接仅供用户点击，不在加载页面时请求网络。

公式应使用已准备的可读 MathML、内联 SVG 或原论文公式裁剪图；可保留公式 ID。这个轻量模板没有 LaTeX/Markdown 转换器或公式排版库，不会自动把 `$...$` 转成公式。不能因为选择网页预览而丢掉公式、用解释替换原式，或将未渲染源码称为排版完成。

## 生成与检查

从技能目录运行下例，将输入和输出替换为本次任务的实际路径；也可以使用脚本的绝对路径，从任意工作目录运行。

```text
python scripts/render_paper_reader.py "任务目录/reader-input.json" --output "任务目录/reader.html"
```

脚本会创建输出父目录，写出 HTML，并报告章节、嵌入图片及来源 ID 数量。输出放任务目录；不写入技能安装目录，不覆盖输入 JSON。更新已经授权的网页工作稿时可使用同一输出路径。

页面提供跟随系统/浅色/深色三态外观并记住手动选择；移动端折叠目录、章节定位、页面滚动进度、回顶；图片按宽度适配并延迟加载，长表格在自身容器滚动。进度只代表页面滚动位置，不代表已读懂或完成证据核验。关闭 JavaScript 时正文、目录、来源链接、系统配色及打印样式仍可使用。

打开实际成品检查桌面与一个窄屏尺寸：目录能定位，窄屏正文不横向溢出，长表自身可滚动，图表及来源链接有效，三种主题可切换，打印不会把正文或宽表留在滚动裁切区。需要打印/导出 PDF 时待图片完成加载后检查预览。没有浏览器工具时明确仅做脚本/结构检查，不声称交互或版面已经验证。

视觉调整优先复用该模板的 CSS；需要新的正文内容回到原阅读分支处理。用户既有页面样式或明确要求优先；不要为了使用预设强制重排其受保护成品。生成本地页面不授权部署、上传论文或发布分享链接。
