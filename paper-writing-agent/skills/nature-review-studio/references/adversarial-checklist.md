# 必要核查

检查只用于解决实际可发生的交付问题：意见有可见证据和解决标准；不编身份、数据、页行和实验；Major/Minor及Blocking一致；意见子问全部覆盖；DONE与真实修改匹配；回信与净稿/标改稿同步；图表编号和引用位置真实；作者/编辑汇总不送给互盲审稿人；保留重要单人发现和真实分歧。

公开文献DOI/PMID、注册号和数据编号用于证据定位，保留；匿名化仅处理实际需要保密的身份/隐私，不一律剥除科研标识。科学问题与必要缺项应在报告中透明呈现，不因旧“silent”字样隐瞒限制。

不设重叠率或最低问题数，不为了命中清单改研究方案。语言和文件格式按用户要求，不以内置规范反向覆盖用户。缺依赖/视觉检查未完成如实报告，不能把脚本退出0当作科学审稿通过。
