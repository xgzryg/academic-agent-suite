# 便携工作流

review：先核材料范围和当前版本，按适用维度审稿，形成独立报告或明确标为虚拟视角报告。单审稿子任务不再递归启动多人。真实独立多审稿人分别完成后才给作者/编辑汇总；保留重要单人意见和真实差异。意见、证据位置与解决标准同步。

respond：真实审稿意见与模拟意见明确区分。按评论拆子问，选择行动和真实完成状态。回复尚未匹配修订产物时标 DRAFTED/REPORTED_DONE_UNVERIFIED，不因存在 revised_manuscript 文件即自动 DONE。缺意见时不能自编为真实审稿意见。只有用户要求模拟审稿或开启循环才模拟。

Word/Markdown用同一payload生成。作者面正式回复通过 Veritas 模板或 Nature Response，不将内部策略标签当作编辑可读行文。用户的格式、语言要求优先，多个内部任务文件不受“恰好两个输出”限制。模拟评估不是实际编辑决定。

update/learn：用户明确要求时运行 ingest_prf.py 提取给定单文件，逐页/逐块阅读。agent把本材料可泛化的 concern、适用条件、响应策略、状态误判、反例和解决标准写到任务目录的经验草稿，每条带 source+page/block 锚点及概括。不得复制历史审稿长段到用户审稿文件；不得把同意语气当作实验完成证据。源文件保留身份时说明未匿名化，不上传或发布。只在本任务采用已核对经验；更改已安装规则或持久记忆需用户明确要求。本模式是资料学习，不是原 NRS 知识图谱或模型训练。

材料缺失或工具失败时说明具体影响，继续可完成部分。不隐藏手稿/回信冲突，不无界重新生成，也不预测录用。
