# 审稿维度与证据

实际12维：novelty-significance；mechanism-evidence；experimental-design；statistical-rigor；reproducibility；clinical-validity；ethical-governance；data-resource-quality；figures-and-tables；writing-clarity；claim-moderation；causal-vs-correlative。

读取 [内置技术分类](../../nature-reviewer/references/technical-concern-taxonomy.md) 和 [核心评价维度](../../nature-reviewer/references/review-axes.md)。这些是检查关注点，不是期刊官方评分表或历史发生率。每项按稿件论断判断适用/不适用/不可评估，不设问题配额。

每条意见有稳定id、claim、evidence、body、resolution和blocking。Major严重性来自对科学论断的影响，Minor是局部报告/表达问题。缺页码可用实际章节/段落，缺材料不写成未做分析。所有Major不自动阻塞；Minor不得阻塞。

同一材料上关注点可不同，事实应一致。独立审稿先完成各报告才比较；不以重叠率约束修改报告，不删除只有一人发现的重大问题。汇总标明对应意见id和共识依据。结论只称模拟评估，不能冒充编辑信或已决定录用。
