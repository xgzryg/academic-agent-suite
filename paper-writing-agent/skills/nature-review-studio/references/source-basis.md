# 来源与当前边界

来源为Nature Review Studio 1.4.1文本规则及Aequitas/Veritas工作流；公开版使用已适配的规则和本分支提供的资料提取、报告渲染脚本。

因此本包不含原始PRF语料、case graph、top-k检索索引、历史severity统计或原训练/蒸馏管线。保留可审读聚合规则，融合新版Nature Reviewer/Response限制，并提供原创本地渲染与资料提取脚本。公开包不附本机历史原件；运行不依赖外部案例库或原项目目录。

资料提取输出包含输入本身的文本，可能包含身份。agent只有在用户明确要求资料学习时使用；不默认更新安装文件、不自动匿名化、不自动联网抓取或共享。来源署名与许可说明以公开包随附文件为准。
