# 便携整合规则

当前用户请求、宿主和包内 [共享规则](../../references/shared-rules.md) 优先。本分支保留已适配的角色规则和包内运行资源；公开包不附本机历史归档。运行时读取当前分支 SKILL.md 及其包内引用，不需要其他机器上的原始安装目录。

- 只处理已确认材料范围；模板和案例中的数字、声明与实验不是用户事实。公共文献的 DOI、PMID、NCT、数据 accession 是证据定位符，不能为了匿名化一律删除。只按实际匿名审稿/隐私要求处理身份信息。
- 用户只要片段或特定格式时按其要求；完整审稿默认给同内容 DOCX + Markdown，可通过本包 NRS 渲染器完成。内部分工材料不受旧“恰好两个文件”数量限制。
- 2—5 个视角可作为普通审稿的虚拟视角，但同一上下文不能声称独立或互盲。启用审稿返修循环时，主调度器实际启动独立审稿子agent和返修子agent；某子agent被分配单份审稿时只完成该份，不递归再启动3人。
- 多人独立审稿只在确有隔离上下文时声明；先确定材料与关注点，再分别完成，最后汇总。自然重复与分歧均保留，不为满足35%等重叠阈值改写结果；重要单人发现也保留。
- 模拟轮次使用 decision_type=simulation，不伪造真实编辑决定，不触发正式返修的 Major/Minor 必答门槛。正式决定已明确则复用；未明确且其内容实质影响正式策略时只暂停依赖该决定的部分。
- DONE/VERIFIED_DONE 只表示已核对实际修改产物。作者口头说明用 REPORTED_DONE_UNVERIFIED，草稿、拟分析、待实验分别标注，不能用措辞把未完成变成完成。
- 不强制新增统计分析、图形或防御文字。规范清单按设计和中心论断判适用性，不能将某一阈值或未提供材料自动判为缺陷。
- 回信、全文、图表与引文的同步核查随本次实际编辑范围进行；不因同一文件未变化而无界重复核查。源文件受保护，授权工作稿可继续修改，不机械每轮复制所有文件。
