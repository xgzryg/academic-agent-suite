# Figure evidence and routing

Adapted from local figure multi-panel architecture guidance. For concept
schematics/graphical abstracts read
[paper-graphical-abstract](../../paper-graphical-abstract/SKILL.md); for real-data
plots, tables and slide figures read
[paper-research-artifacts](../../paper-research-artifacts/SKILL.md). Use current
official stage/format instructions from the named journal; no implicit external
image API, backend-preference persistence or new generic audit infrastructure.

Start with the scientific question, figure-level claim, decisive evidence and
what would overturn or limit it. Select panel roles the evidence actually needs:
setup, representative example, primary estimate, comparison/control,
decomposition, stratification, orthogonal validation, perturbation, boundary or
mechanistic evidence. Panel letters indicate reading order rather than fixed
functions; do not add a decorative panel or six figures by template.

Useful argument sequences include a validation envelope, population-to-instance
explanation, discovery sequence and progressively stronger capability claims.
Choose the sequence the real study supports; a chronological lab record or four
versions of the same performance metric may not make four necessary panels.

Keep conclusion-changing negative evidence and boundaries visible. Supporting
checks can move to SI only when interpretation remains clear. Show the strongest
evidence prominently while making controls and uncertainty legible. For direct
comparisons align encodings, scales, definitions and denominators; explicitly
state meaningful changes in cohort, n or estimator. Existing style/approved
figures and journal requirements outrank arbitrary panel-count/aspect defaults.

Render and inspect the result at useful final size: labels, units, axes,
uncertainty, caption mapping and readability. Automated geometry checks can
support inspection but do not establish scientific correctness. Do not claim
visual verification when the rendered file was not opened. Recheck the actual
changed elements instead of repeating an unchanged audit loop.
