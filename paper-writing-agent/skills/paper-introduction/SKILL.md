# Introduction前言

先读取并遵守[共享规则](../../references/shared-rules.md)。仅完成已授权的前言工作；用户给定框架或现稿时复用，不重新强制整套流程。

## 输入复用与分支选择

- 读取当前标题、摘要、研究问题、实际结果及详细图注、目标期刊/受众、已定框架、文献综述和可选风格范文。材料不足时先利用现有内容，不重复索取。
- PDF/Word通过[PDF分支](../paper-pdf/SKILL.md)和[文档分支](../paper-documents/SKILL.md)读取；需要检索文献、核验引用或系统理解论文证据时主动读取[文献检索与精读分支](../paper-literature-reading/SKILL.md)执行。
- 在进入拟稿前明确目标语言与字数单位；源中800字/800-word混用不能沿用。具体篇幅按用户和期刊，未指定的次要偏好可说明合理默认。
- 区分本研究事实、支持文献和风格范文；范文不得作为本研究结果或引用来源。

## 阶段一：框架

1. 若尚无确定框架，基于研究问题、结果和受众给三种有实质差异的方案及取舍理由；简单局部任务不需要三套方案。
2. 每个方案写主题、段落功能、拟覆盖内容、篇幅预算与文献检索关键词；research gap要具体到尚未回答的问题，不能只说“研究不足”。
3. 默认从较广背景收敛到具体缺口和研究目标，各段逻辑相接，研究重要性有事实支撑。问题与目标及时出现，结尾清楚说明研究目的，不重复夸张。
4. 用户需在不同叙事方向间决定时保留框架选择；已有明确框架或明确授权选择方案时直接沿用，不为每个后续段落新增审批。

## 阶段二：文献调研

1. 围绕采用的框架组织检索/审读，保留research gap，文献检索提纲可去掉本研究目标和逐段字数限制。
2. 优先近期高质量且直接相关的原始证据，同时保留必要经典文献；“近五年/top期刊”是偏好而非排他标准。
3. 已有综述材料先审读，缺口按当前联网边界补查。没有联网或数据库权限时给明确的证据缺口与检索词，不伪称完成检索；不增加来源没有的独立联网批准制度。
4. 按框架形成客观、深入、批判性的证据材料：哪些结论一致、哪些有争议、研究空白是否成立，各论点定位到文献。多模型/多份综述可作为线索，不能互相引用来替代原始证据。
5. 综述可以长于正式前言，源建议2至3倍仅作材料充足度参考，不固定字数。

## 阶段三：前言全文

1. 对综述内容决定保留、修订、删除及必要补充，简明解释影响主线的取舍；沿确定框架规划段落与篇幅。
2. 起草仅Introduction范围内的完整文本。让主题句、支持证据和过渡连贯，采用清晰、正式、易懂的学术语言，首现专业术语按需要定义。
3. 学习指定范文的结构与文风，调整句长、主动表达和衔接；不得搬运其案例事实、数据或引文。
4. **原有文内引文按源样式与内容原样保留。** 不擅改作者年份、编号或将引文挪到不支持的论点。需要新增事实但证据未补齐时标注`(citation needed)`，同时说明尚未核验；不虚构引用。
5. 结尾对准本研究问题、目的和可支持的贡献。关联证据不得改成因果、未核实“首次”不能写入。

## 实际产物、核验与停止

- 框架任务交付方案及检索关键词；调研任务交付有依据的分主题综述；全文任务交付完整前言、必要取舍说明和具体引文/事实缺口。不要无差别追加未请求的Methods或Discussion。
- 检查框架、字数单位、研究gap、术语、引文及数字是否与实际研究一致；检查所有新 factual claim 是否有证据或明确待补标记。
- 缺少会改变研究主题、关键结论或框架方向的信息时暂停依赖部分，继续材料整理；已明确的写作部分照常完成。
- 用户要求Word/PDF成品时读取[文档分支](../paper-documents/SKILL.md)或[PDF分支](../paper-pdf/SKILL.md)执行。

## 来源与适配

写作流程参考迪娜学姐的论文写作提示词经验，并已整理为以上可独立执行的任务规则。公开包不附原课程PDF；执行无需读取原文件、页码或历史模型示例。来源署名保留，未另行赋予原材料再分发许可。
